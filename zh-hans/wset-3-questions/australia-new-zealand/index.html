WSET Level 3 澳大利亚与新西兰：练习题与解答

这些题目来自 The Wine Goat 题库中的澳大利亚与新西兰单元，依照 WSET Level 3 葡萄酒认证（Award in Wines）课程大纲编写。作答、阅读解析，然后在 App 里练习完整的 83 题；你答错的题目会不断回来，直到你真正记住为止。

练习题与解答（The Wine Goat 题库）

1 澳大利亚最主要的葡萄品种（不分红白）是哪一个？

显示答案

答案： Shiraz

原因： Hunter 与 Barossa 出产饱满、果味丰富的 Shiraz；Geelong 与 Heathcote 则较精瘦、带胡椒味。与 Cabernet 混调时，它扮演的是 Merlot 在 Bordeaux 混调中的角色。

2 澳大利亚的 Cabernet 与 Shiraz 相比，一般有什么不同？

显示答案

答案： 颜色更深，单宁更扎实，酸度更高

原因： 成熟的黑醋栗与黑樱桃，常带烘烤橡木桶风味；经典产区为 Coonawarra 与 Margaret River。Merlot 多用于混调。

3 澳大利亚最好的 Pinot Noir 来自哪里？

显示答案

答案： Yarra Valley、Mornington Peninsula 与 Tasmania

原因： 风格：中等酒体与酒精，中高酸度，樱桃与草莓风味。炎热产区则适合 Grenache、Petit Verdot 与 Mataro。

4 澳大利亚地理标志（GI）的层级为何？

显示答案

答案： 区域（Zone）、产区（Region）、子产区（Subregion）

原因： 区域（Zone）是大范围地带；产区（Region）必须具有明确特色。Eden Valley 位于 Barossa 区域内，属于 South Australia，而 South Australia 又属于 South Eastern Australia。

5 哪个产区是澳大利亚 Sauvignon Blanc 的标竿？

显示答案

答案： Adelaide Hills

原因： 浓缩的百香果风味与高酸度。最主要的白葡萄品种 Chardonnay，风格从使用橡木片的混调酒款，到凉爽产区均衡的酒款都有。

6 除了大量生产的酒款外，Riverina 还专精于哪一种风格？

显示答案

答案： 贵腐 Semillon，得益于秋季清晨的雾气

原因： 它位于 New South Wales。

学习笔记：WSET Level 3 澳大利亚与新西兰

WSET Level 3 的澳大利亚与新西兰题目，奖励的是能把每款知名葡萄酒联系到让其产区降温或塑造其风格之因素的考生。澳大利亚大部分地区温暖到炎热，因此质量取决于海拔、纬度与海风等降温因素。新西兰全境都是凉爽的海洋性气候，所以挑战在于让葡萄成熟，而不是炎热。这份笔记的内容比上面的练习题更深入，并依照考试评分的方式编排：原因、效果与风格。

WSET Level 3 澳大利亚：气候与降温因素

澳大利亚的葡萄酒产区大多位于东南部与西南部，因为北部太过炎热潮湿。许多内陆地区炎热干燥，干旱、缺水与土壤盐化都是实际的限制。灌溉、机械采收与大规模酒厂，让内陆产区能以低成本生产大量稳定、果味丰富的葡萄酒。相对地，高级产区则仰赖一种或多种降温因素。

  • 海拔：Adelaide Hills、Eden Valley 以及 Clare Valley 的部分地区比周围低地凉爽，能保留酸度。
  • 纬度：最南端的州 Tasmania 够凉爽，适合生产起泡酒、Pinot Noir 与 Chardonnay。
  • 海洋影响：海风为 McLaren Vale、Mornington Peninsula 与 Margaret River 降温；南冰洋与印度洋调节了气温。
  • 云层与湿度：在 Hunter Valley，午后云层与湿度缓和了炎热，但也在采收期带来降雨与腐烂的风险。

老藤与根瘤蚜

包括 Barossa Valley 在内的 South Australia 从未受过根瘤蚜侵害，并以严格的检疫规定加以保护。因此，这里拥有一些世界上最古老、以自根种植的葡萄树，尤其是 Shiraz 与 Grenache。老藤产量低、果实浓缩，生产者常在酒标上强调这一点。

澳大利亚酿酒的主题

澳大利亚的酿酒技术非常精准。在温暖产区，加酸很常见，因为葡萄在保留足够天然酸度之前就已达到高糖度。平价酒款可能使用橡木片或橡木条，以较低成本取得橡木风味。高级 Chardonnay 已从重橡木、黄油感的风格，转向来自凉爽产区、更精瘦清新的酒款，新橡木桶与乳酸转换的使用也更为节制。Hunter Semillon 是温暖气候成熟度的经典例外：它在低糖度时提早采收、低温发酵、不经橡木桶就装瓶，所以它所有的烘烤风味都来自瓶中陈年。

酒标规定

澳大利亚的酒标诚信计划（Label Integrity Program）采用 85% 规则：如果酒标上标示品种、年份或地理标志（GI），至少 85% 的酒必须来自该品种、年份或产地。混调酒款常按比例由高到低列出品种，例如 Cabernet-Merlot 或 Shiraz-Viognier。地理标志的层级由区域（Zone）到产区（Region）再到子产区（Subregion）。

应考技巧：解释一款澳大利亚葡萄酒时，一定要说出降温因素。好的答案是这样写的：Eden Valley 的海拔比 Barossa 谷地高，所以夜晚更凉爽，减缓了成熟速度并保留高酸度，因此酿出带莱姆果香的不甜 Riesling。

WSET Level 3 新西兰：凉爽的海洋性气候

在 WSET Level 3 中，新西兰葡萄酒的特征是凉爽的海洋性气候：没有任何葡萄园离海很远，而狭长的岛屿横跨了很大的纬度范围。北岛一般较温暖潮湿；南岛较凉爽、日照较多，某些产区的日夜温差很大。漫长的生长季、强烈的日照与凉爽的夜晚，能带来成熟的果味，同时保留高酸度。

Marlborough Sauvignon Blanc

位于南岛东北部的 Marlborough 是新西兰最大的产区，也是新西兰种植最多的品种 Sauvignon Blanc 的故乡。晴朗的白天与寒冷的夜晚带来浓郁、强烈的香气与高酸度。Wairau Valley 排水良好的多石土壤，以及较凉爽干燥的 Awatere Valley，造就了略有不同的风格。酿造方式通常以保护为主：在不锈钢槽中低温发酵、不用橡木桶并提早装瓶，以保留百香果、醋栗、西柚与青椒的香气。有些生产者会通过橡木桶发酵、酒泥接触或野生酵母来增加复杂度。

新西兰其他重要产区

  • Hawke's Bay（北岛）：温暖晴朗，最知名的是 Merlot 与 Cabernet Sauvignon 的 Bordeaux 风格混调，以及 Syrah，尤其是在排水良好的 Gimblett Gravels。
  • Gisborne（北岛）：温暖，以成熟、果味丰富的 Chardonnay 闻名。
  • Martinborough / Wairarapa（北岛）：干燥多风，出产浓缩的 Pinot Noir。
  • Central Otago（南岛）：最南端的产区，也是唯一属于大陆性气候的产区；日夜温差大、有霜害风险、生长季短，造就果味浓郁、酸度高的 Pinot Noir。
  • Nelson 与 Canterbury/Waipara（南岛）：凉爽产区，出产 Pinot Noir、Riesling、Chardonnay 与芳香型白葡萄酒。

新西兰的酒标对品种、年份与产区也采用 85% 规则。旋转瓶盖几乎无所不在，有助于保留清新、果味丰富的风格。

常见错误：把 Central Otago 描述成和新西兰其他地区一样的海洋性气候。它位于内陆、属于大陆性气候，这就是为什么那里白天炎热、夜晚寒冷、有霜害风险，也是它的 Pinot Noir 果味如此浓郁的原因。

示例解析：关于 Coonawarra Cabernet Sauvignon 的简答题

澳大利亚的题目常要求你解释为什么某个产区以某个品种闻名。答案应该结合气候、土壤与最终风格。

题目：解释为什么 Coonawarra 以高质量的 Cabernet Sauvignon 闻名。

参考答案：Coonawarra 位于 South Australia 东南部，纬度相对偏南且靠近南冰洋，因此气候比该州大部分地区凉爽。凉爽的海风与漫长的生长季，让晚熟的 Cabernet Sauvignon 能缓慢成熟，发展出完整的风味与成熟的单宁，同时保有良好的酸度。这个产区以 terra rossa 闻名，那是一条覆盖在石灰岩上、排水良好的红色土壤带，水分容易排出、树势受到限制，因而产量较小、葡萄浓缩。这些酒酒体饱满，带黑醋栗果味，单宁扎实但成熟，常带有独特的薄荷或尤加利气息，通常经橡木桶陈年。它们的结构与浓缩度让它们能在瓶中良好陈年。

为什么这样写有效：答案说出了降温因素（纬度与海洋）、土壤及其对树势的影响，最后精确描述了风格与陈年潜力。每个事实都联系到一个结果。

品酒单元中的澳大利亚与新西兰

WSET Level 3 有两个独立的单元：理论（选择题与简答题）与品酒（用 SAT 盲品评估两款酒）。每个单元都需要至少 55%，没过的单元单独重考。这两个国家的葡萄酒是很好的品酒练习。一款 Marlborough Sauvignon Blanc 通常是浅柠檬色，带有明显的百香果、醋栗、西柚与青椒香气，不甜、酸度高、中等酒体。一款 Barossa Shiraz 则是深宝石红色，带有明显的黑莓、李子、甜香料，常有来自橡木桶的香草，不甜、酒精高、单宁高但成熟、酒体饱满。

应考技巧：遇到香气非常浓郁的酒，不要只写“果香”。精确说出水果类别（热带、柑橘、绿色水果），并加上青椒或草本这类非水果的香气；精确的描述词在品酒单元能拿到更多分数。

以文字作答的练习题

题目：为什么 Tasmania 很适合生产传统法起泡酒？答案：它是澳大利亚最南端的州，气候凉爽，Chardonnay 与 Pinot Noir 在这里缓慢成熟，保留了基酒所需的高酸度与细致果味。

题目：什么是 Gimblett Gravels？答案：Hawke's Bay 的一个区域，拥有来自古老河床、深厚多石且排水良好的土壤。石头能保存热量并限制树势，帮助 Merlot、Cabernet Sauvignon 与 Syrah 完全成熟。

题目：为什么 Riverland 这类内陆产区要仰赖灌溉？答案：那里炎热干燥，葡萄树需要额外的水分才能存活并维持高产量。引用 Murray River 及其支流的水灌溉，使大量生产平价、果味丰富的葡萄酒成为可能。

题目：为什么旋转瓶盖在新西兰与澳大利亚如此普遍？答案：它能保护清新、芳香的葡萄酒不受氧气影响，并避免软木塞污染，有助于保留 Sauvignon Blanc 与 Riesling 等风格赖以定义的一级果香。

澳大利亚与新西兰的常见错误

  • 说澳大利亚全境都很炎热：高级产区仰赖海拔、纬度与海风等降温因素。
  • 把 Marlborough 放在北岛：它位于南岛的东北角。
  • 把 Hunter Semillon 描述成经橡木桶且酒体饱满：它通常不过橡木桶、酒精低，并通过瓶中陈年发展出烤面包与蜂蜜风味。
  • 忘了 Barossa 与 Eden Valley 是邻居，风格却非常不同：温暖谷地的 Shiraz，对比海拔较高、较凉爽的 Riesling。
  • 把 Gisborne 和 Hawke's Bay 搞混：Gisborne 以 Chardonnay 最为知名，Hawke's Bay 则以 Bordeaux 混调与 Syrah 闻名。
  • 写新西兰酒标采用 75% 规则：品种、年份与产区的规则是 85%。

在 WSET Level 3 中，重要的凉爽或受调节产区包括 Tasmania（纬度）、Yarra Valley 与 Mornington Peninsula（Victoria）、Adelaide Hills 与 Eden Valley（海拔）、Coonawarra（偏南的凉爽位置）以及 Margaret River（海洋性）。它们出产的 Chardonnay、Pinot Noir、Riesling、Sauvignon Blanc、优雅的 Cabernet Sauvignon 与起泡酒，酸度都比温暖地区更高。

为什么 Hunter Valley Semillon 的酒精这么低？

Hunter Valley Semillon 在低糖度时就提早采收，部分原因是为了避开潮湿亚热带气候下采收期的降雨与腐烂。低糖度带来低酒精，通常约 10 到 11%，以及非常高的酸度。它以低温发酵、不经橡木桶装瓶；随着瓶中陈年，会发展出烤面包、蜂蜜与坚果的风味，可能让人联想到橡木桶，尽管完全没有使用。

为什么 Marlborough Sauvignon Blanc 的风味如此浓烈？

Marlborough 结合了明亮的日照与凉爽的夜晚，所以葡萄成熟缓慢，在保留高酸度的同时累积浓郁的香气。排水良好的多石土壤限制了树势。以保护为主的酿造方式，也就是在不锈钢槽中低温发酵、不用橡木桶，保留了让这种风格闻名的浓烈百香果、醋栗与青椒特征。

新西兰哪个产区最适合 Pinot Noir？

Central Otago 是新西兰最知名的 Pinot Noir 产区：它是最南端的产区，属于大陆性气候，白天炎热、夜晚寒冷、有霜害风险，酿出果味浓郁、酸度高的酒。Wairarapa 的 Martinborough 也很有名，Marlborough、Nelson 与 Canterbury 也能酿出优质的 Pinot Noir。

澳大利亚的 GSM 混调是什么？

GSM 是 Grenache、Shiraz 与 Mataro（Mourvèdre）的混调，灵感来自南罗讷河。它是 Barossa Valley 与 McLaren Vale 等 South Australia 温暖产区的特色，那里仍保有 Grenache 与 Mataro 的老藤灌木式葡萄树。Grenache 带来红色水果与酒精，Shiraz 带来颜色与酒体，Mataro 则带来单宁与咸香风味。

Coonawarra 的 terra rossa 是什么？

Terra rossa 是 Coonawarra 一条覆盖在石灰岩层上的红色土壤带。它排水良好，所以葡萄树不会过度茂盛、产量适中，而石灰岩则能为干燥时期保留一些水分。结合 Coonawarra 的凉爽气候，它帮助 Cabernet Sauvignon 缓慢成熟，酿出酒体饱满、带黑醋栗果味、单宁扎实，且常带薄荷气息的酒。

为什么 Tasmania 在 WSET Level 3 中很重要？

Tasmania 是澳大利亚最南端、最凉爽的葡萄酒产区。它漫长凉爽的生长季，适合需要保留高酸度的早熟品种：用于传统法起泡酒的 Chardonnay 与 Pinot Noir，以及优雅的静态 Pinot Noir、Chardonnay 与 Riesling。在考试作答时，把 Tasmania 联系到纬度这个降温因素，以及起泡酒这个关键风格。

为什么澳大利亚人说 Shiraz，新西兰人却常说 Syrah？

这是同一个品种。在澳大利亚，Shiraz 这个名称用于经典的丰厚、成熟、酒体饱满的风格，尤其是来自 Barossa Valley 与 McLaren Vale 的酒。Hawke's Bay 等较凉爽产地的生产者常使用 Syrah，表示风格更清新、胡椒味更明显，更接近北罗讷河。考试时要认得这两个名称，并把各自的风格联系到它的气候。

Marlborough Sauvignon Blanc 会出现在 WSET Level 3 的品酒考试中吗？

会，它是芳香型、高酸度白葡萄酒的经典示例，常出现在品酒练习中。用精确的 SAT 用语描述它：浅柠檬色、香气强度明显、百香果、醋栗、西柚与青椒、不甜、酸度高、中等酒体。品酒是一个独立的单元，需要至少 55%，所以规律的盲品练习非常重要。

如果 WSET Level 3 理论通过、品酒没过，需要整场考试重考吗？

不需要。理论与品酒是两个独立的单元，每个都需要至少 55%。如果有一个单元没过，你只需要重考那个单元；另一个单元的通过成绩会保留。规划准备时要让两个单元都有规律的练习，因为理论的高分无法弥补品酒的弱势。
