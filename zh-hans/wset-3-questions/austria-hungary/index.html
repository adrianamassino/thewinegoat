WSET Level 3 奥地利与匈牙利：练习题与解答

这些题目来自 The Wine Goat 题库中的奥地利与匈牙利单元，依照 WSET Level 3 Award in Wines 课程大纲编写。先作答、阅读解析，再到 App 练习完整的 57 题；答错的题目会反复出现，直到你真正掌握为止。

样题与解答

1 奥地利最为人所知的是什么？

显示答案

答案：以 Grüner Veltliner 和 Riesling 酿造的优质不甜白葡萄酒

解析：奥地利也出产优质红葡萄酒（Zweigelt、Blaufränkisch），以及受贵腐菌感染的 Welschriesling 甜酒。

2 奥地利葡萄酒产区属于哪种气候？

显示答案

答案：凉爽大陆型气候，夏季短、冬季严寒

解析：阿尔卑斯山占据西部，因此葡萄园都在东部。北部有凉风吹拂，靠近匈牙利边界则有温暖的东风。

3 奥地利种植最广的葡萄品种是哪一种？

显示答案

答案：Grüner Veltliner

解析：高产量时表现平淡；用心栽培则酒体饱满、风味集中、酸度高，带柑橘或核果香气，有时有白胡椒味，陈年后发展出蜂蜜与烤面包香。

4 Welschriesling 和 Riesling 是同一个品种吗？

显示答案

答案：不是，它是不同的品种

解析：它是奥地利第二重要的白葡萄：酿成不甜酒时简单且酸度高，但容易感染贵腐菌，能酿出优质甜酒。

5 奥地利最好的 Riesling 来自哪里？

显示答案

答案：Wachau、Kamptal、Kremstal

解析：通常为不甜、中等至饱满酒体，带成熟水蜜桃香气；最好的酒款能在瓶中陈年。

6 Sauvignon Blanc 在奥地利哪个产区的声誉日益提升？

显示答案

答案：施泰尔马克（Styria）

解析：这是位于南部的产区；Chardonnay 和 Müller-Thurgau 在当地也广泛种植。

学习笔记：WSET Level 3 的奥地利与匈牙利

WSET Level 3 关于奥地利与匈牙利的题目，集中在两个重点：奥地利以 Grüner Veltliner 和 Riesling 酿造的高质量不甜白葡萄酒，以及布尔根兰的甜酒；还有匈牙利的托卡伊（Tokaj），世界最伟大的贵腐甜酒之一。两国都属于凉爽大陆型气候，水域、温暖的风与秋季晨雾在这里影响甚大。这份笔记的内容超出上方样题，并依照考试评分所用的“原因、结果、风格”逻辑编排。

WSET Level 3 的奥地利：产区与气候

奥地利的葡萄园位于国家东部，因为西部被阿尔卑斯山覆盖。气候为凉爽大陆型，冬季寒冷、夏季温暖。在下奥地利（Niederösterreich），来自北方与森林的冷空气有助于保留酸度；往匈牙利边界的布尔根兰（Burgenland）走，来自潘诺尼亚平原的较暖空气，让这里能酿出更饱满的红葡萄酒与甜酒。河流与湖泊调节气温，而在新锡德尔湖（Neusiedl）周边，更创造出贵腐菌所需的湿度。

下奥地利：Wachau、Kamptal、Kremstal、Weinviertel

瓦豪（Wachau）是多瑙河沿岸一段狭长的河谷，陡峭的梯田葡萄园建在原生岩上。白天温暖、夜晚凉爽，加上北方森林丘陵吹下的冷空气，使白葡萄酒兼具成熟果香与高酸度。紧邻东侧的坎普谷（Kamptal）与克雷姆斯谷（Kremstal）出产类似的 Grüner Veltliner 与 Riesling，常种在黄土与岩石土壤上。威非尔特（Weinviertel）是奥地利最大的产区，经典酒款是清新、带胡椒味的 Grüner Veltliner；它也是第一个采用 DAC 制度的产区。

Wachau 质量等级

等级酒精浓度风格
Steinfeder最高 11.5% abv轻盈、清新、不甜，适合年轻时饮用
Federspiel11.5% 至 12.5% abv中等酒体、不甜、优雅
Smaragd至少 12.5% abv最成熟的葡萄，酒体饱满、不甜、具陈年潜力

这些等级由 Wachau 的一个酒农协会使用，依成熟度与酒体区分不甜酒。由于它们是 Wachau 独有的，因此是选择题的常见考点。

Burgenland 与 Steiermark

布尔根兰是最温暖的产区。水浅的新锡德尔湖（Neusiedlersee）在秋季产生晨雾，接着温暖干燥的午后让葡萄浓缩，因此贵腐菌能稳定生成。贵腐甜酒以 Welschriesling 及其他品种酿造，鲁斯特（Rust）镇则以 Ruster Ausbruch 闻名。布尔根兰也是奥地利主要的红葡萄酒产区：Blaufränkisch 颜色深、酸度高、单宁扎实，带黑樱桃与香料风味，在中布尔根兰（Mittelburgenland）表现尤其出色；Zweigelt 是奥地利种植最多的黑葡萄（Blaufränkisch 与 St. Laurent 的杂交品种），较柔和、果香丰富、容易入口。南部的施泰尔马克（Steiermark，英文 Styria）葡萄园多在丘陵上，以清爽芳香的 Sauvignon Blanc 著称。

奥地利葡萄酒法规：DAC 与 Prädikat

奥地利葡萄酒法规结合了德国式的成熟度分级，以及较新的产区制度。DAC（Districtus Austriae Controllatus）制度把每个产区与其典型品种和风格联系起来，因此酒标优先标示产地而非品种；例如 Weinviertel DAC 就代表 Grüner Veltliner。如今许多 DAC 采用产区级、村庄级与单一葡萄园级的金字塔结构。

  • Qualitätswein：来自单一指定产区的优质葡萄酒，是不甜酒的主要等级。
  • Prädikatswein：与德国相同，依采收时葡萄的糖分高低分级：Spätlese、Auslese、Beerenauslese、Trockenbeerenauslese 与 Eiswein。
  • Ausbruch：介于 Beerenauslese 与 Trockenbeerenauslese 之间的传统等级，与鲁斯特（Rust）密切相关。
  • Strohwein 或 Schilfwein：采收后把葡萄放在稻草或芦苇上风干所酿成的甜酒。
  • 与德国不同，奥地利的 Prädikat 葡萄酒几乎都是甜的；Spätlese 及以上等级不得加糖（chaptalisation）。

考试技巧：如果题目要你描述 Grüner Veltliner，除了风味也要写结构。高分答案：中等至饱满酒体、高酸度，带柑橘、青苹果与核果香气，以及典型的白胡椒调性；来自 Wachau 与 Kamptal 的顶级酒款陈年后会发展出蜂蜜与烤面包香。也别忘了提到高产量时会酿出简单轻盈的酒。

WSET Level 3 的匈牙利：托卡伊（Tokaj）

托卡伊位于匈牙利东北部，火山丘陵上的葡萄园与博德罗格河（Bodrog）、蒂萨河（Tisza）在此交会。秋季时河流产生晨雾，促进贵腐菌生成，而温暖干燥的午后则让萎缩的果粒浓缩。这里属于大陆型气候，漫长干燥的秋季使延迟采收成为可能。

托卡伊的葡萄品种

  • Furmint：主要品种，酸度高、容易感染贵腐菌，能酿出优质的不甜酒与甜酒。
  • Hárslevelű：芳香、带花香，常与 Furmint 混调。
  • Sárgamuskotály（Muscat Blanc à Petits Grains）：少量使用，增添葡萄般的芳香。

Tokaji Aszú 如何酿造

  1. 受贵腐菌感染的（aszú）果粒逐粒手工采摘，通常要在葡萄园中分多次采收。
  2. 以健康葡萄酿成基酒或正在发酵的葡萄汁。
  3. 将 aszú 果粒压成泥状，浸泡在基酒或葡萄汁中，萃取糖分、酸度与风味。
  4. 压榨后缓慢完成发酵，并在凉爽潮湿的地下酒窖中，以小型橡木桶陈年。
  5. 成品是甜酒，酸度高，带杏、柑橘果酱、蜂蜜香气，陈年后出现坚果与焦糖风味。

甜度传统上以 puttonyos 表示，也就是加入一桶基酒中的 aszú 果粒篓数。如今 Tokaji Aszú 必须达到很高的最低残糖量，因此过去较低的 3 与 4 puttonyos 等级已不再使用；5 与 6 puttonyos 仍可能出现在酒标上。

在托卡伊以外，匈牙利也以 Kékfrankos（即 Blaufränkisch）、Cabernet Franc 及混调酿造红葡萄酒，尤其是埃格尔（Eger）与维拉尼（Villány）；但在 WSET Level 3，大部分题目都集中在托卡伊。

常见错误：把 Eszencia 当成和 Aszú 一样。Eszencia 只是 aszú 果粒在自身重量下自然流出、如糖浆般的汁液；它甜到要发酵好几年，酒精浓度仍然非常低。

示例解析：奥地利与托卡伊的简答题

简答题看重清楚的因果链。以下是一道典型题目与一份参考答案，最后说明为什么它能拿高分。

题目：说明新锡德尔湖周边与托卡伊的自然条件如何有利于生产高质量甜酒，并描述 Tokaji Aszú 的酿造方式。

参考答案：两个地区的葡萄园附近都有水域。秋季时水域产生晨雾，湿气让灰霉菌（Botrytis cinerea）以贵腐的形式生长。接着温暖干燥的午后阻止霉菌转变为灰腐病，并让果粒失去水分，使糖分、酸度与风味浓缩。大陆型气候中漫长干燥的秋季，让酒农能分多次延迟采收。在托卡伊，Furmint 是理想的品种，因为它非常容易感染贵腐菌，又能保持高酸度，平衡甜味。酿造 Aszú 时，萎缩的果粒逐粒采摘、压成泥状，浸泡在基酒或正在发酵的葡萄汁中；接着压榨，缓慢完成发酵，并在凉爽潮湿的酒窖中以小桶陈年。成品是酸度高、带杏、柑橘果酱与蜂蜜香气的甜酒，可陈年数十年。

为什么有效：每个要点都联系到它的结果（晨雾导致贵腐、干燥午后导致浓缩、酸度平衡糖分）。只列出事实而没有联系，得分会比较少。答案也点出品种，并以正确顺序写出关键步骤，这正是阅卷者要找的内容。

样题文字解答

题目：酒标上写着 Wachau Federspiel，这代表什么？答案：这款酒来自 Wachau，属于当地三个等级中间的那一级，是酒精浓度中等的不甜酒，比 Steinfeder 饱满，但比 Smaragd 轻盈。品种很可能是 Grüner Veltliner 或 Riesling。

题目：为什么奥地利能在凉爽大陆型气候中酿出高质量的不甜白葡萄酒？答案：多瑙河沿岸面南的陡峭梯田斜坡能接收更多日照，而从丘陵吹下的夜间冷空气让酸度维持在高档。河流也有调节气温的作用。成熟的风味加上高酸度，造就了典型的结构。

题目：什么是 Szamorodni？答案：一种托卡伊葡萄酒，以含有部分贵腐果粒的整串葡萄酿成，而非使用挑选出的 aszú 果粒。它可以是不甜（száraz）或甜（édes）；不甜版本常在桶中陈年，可能带有坚果与轻微氧化的调性。

题目：哪一种奥地利红葡萄酒预期单宁最扎实、酸度最高？答案：Blaufränkisch，尤其是来自中布尔根兰的酒款。Zweigelt 则较柔和、果香更丰富。

奥地利与匈牙利的常见错误

  • 把 Welschriesling 和 Riesling 搞混：它们是不同的品种，而 Welschriesling 主要在甜酒方面重要。
  • 以为奥地利的 Spätlese 可以像德国一样是不甜的：在奥地利，Prädikat 等级基本上都是甜酒。
  • 把 Wachau 放在布尔根兰：Wachau 位于维也纳以西、下奥地利的多瑙河畔。
  • 忘了 Smaragd 是最成熟、最饱满的等级，而不是最轻盈的。
  • 写成 Tokaji Aszú 酸度低：Furmint 带来高酸度，这正是这些酒能长久陈年的原因。
  • 把 Eszencia 和 Aszú 搞混：Eszencia 是 aszú 果粒自然流出的汁液，酒精浓度非常低。

品酒单元中的奥地利与匈牙利

WSET Level 3 分成两个独立单元：理论（选择题加简答题）与品酒（以 SAT 盲品评估两款酒）。每个单元都至少需要 55%，如果某个单元没过，只需重考该单元。Grüner Veltliner 与 Riesling 是高酸、未经橡木桶白葡萄酒的典型例子，所以要练习精确描述它们：浅柠檬色、中等(+)香气强度、柑橘与核果、高酸度、不甜。贵腐甜酒则会呈现较高的糖分、杏、蜂蜜与柑橘果酱香气，并由酸度加以平衡。

考试技巧：在品酒单元中，要把结构和质量联系起来。描述一款好的 Grüner Veltliner 时，提到高酸度与成熟果香及中等至饱满酒体取得平衡，而且悠长的余味与香气强度足以支持“非常好”的质量结论。

酒标用语迷你词汇表

  • Ried：奥地利酒标上的单一指定葡萄园。
  • Gebietswein、Ortswein、Riedenwein：奥地利产地金字塔中的产区级、村庄级与单一葡萄园级。
  • Steinfeder、Federspiel、Smaragd：Wachau 的三个等级，由最轻盈到最饱满。
  • Ausbruch：与鲁斯特（Rust）相关的传统甜酒等级。
  • Aszú：受贵腐菌感染而萎缩的果粒，以及托卡伊以这些果粒酿成的甜酒。
  • Száraz 与 édes：不甜与甜，用于 Szamorodni。
  • Eszencia：aszú 果粒自然流出的汁液，极甜。

WSET Level 3 中的 Steinfeder、Federspiel 和 Smaragd 是什么？

它们是 Wachau 不甜白葡萄酒的三个等级，依成熟度与酒精浓度定义。Steinfeder 轻盈，最高 11.5% abv；Federspiel 为中等酒体，介于 11.5% 到 12.5% 之间；Smaragd 来自最成熟的葡萄，酒体饱满，至少 12.5%。主要适用于 Grüner Veltliner 与 Riesling。

奥地利酒标上的 DAC 是什么意思？

DAC 是 Districtus Austriae Controllatus 的缩写。这是奥地利的法定产区制度，把产区与其典型品种和风格联系起来，所以产区名称本身就代表了这款酒。例如 Weinviertel DAC 是带胡椒味的 Grüner Veltliner，其他 DAC 则涵盖 Riesling、Blaufränkisch 或 Sauvignon Blanc。如今许多 DAC 会区分产区级、村庄级与单一葡萄园级酒款。

为什么 Furmint 在托卡伊如此重要？

Furmint 是托卡伊的主要品种，因为它同时具备非常高的酸度与容易感染贵腐菌的薄皮。高酸度能平衡 Aszú 与 Eszencia 的极高甜度，并帮助它们陈年数十年。Furmint 也能酿出高质量的不甜酒，因此能展现托卡伊所有的风格范围。

Tokaji 中的 puttonyos 是什么意思？

Puttonyos 指的是用来收集 aszú（贵腐）果粒的传统篓子；加入一桶基酒中的篓数代表甜度。如今 Tokaji Aszú 必须达到很高的最低残糖量，因此旧有的 3 与 4 puttonyos 等级已经消失，而 5 与 6 puttonyos 仍可标示在酒标上。

WSET Level 3 需要知道哪些奥地利红葡萄品种？

要学 Zweigelt 和 Blaufränkisch。Zweigelt 是奥地利种植最多的黑葡萄，是 Blaufränkisch 与 St. Laurent 的杂交品种，酿出柔和、果香丰富、带红樱桃风味、适合年轻时饮用的酒。Blaufränkisch 在布尔根兰表现尤其好，颜色较深、酸度高、单宁扎实，带黑色水果与香料风味，具陈年潜力。St. Laurent 与 Pinot Noir 也有种植。

WSET Level 3 关于 Tokaji Aszú 的简答题该怎么回答？

先写自然条件：产生秋季晨雾的河流、干燥的午后与漫长的秋季。接着解释为什么 Furmint 适合贵腐并能保持酸度。依序描述步骤：手工采摘 aszú 果粒、压成果泥、浸泡于基酒或葡萄汁中、缓慢发酵，以及在潮湿酒窖中桶陈。最后写风格：甜、高酸度、杏、柑橘果酱、蜂蜜，具长期陈年潜力。

Grüner Veltliner 会出现在 WSET Level 3 品酒考试中吗？

有可能，因为它是高酸、未经橡木桶白葡萄酒的经典例子。练习用精确的 SAT 用语描述它：浅柠檬色、中等(+)香气强度、柑橘、青苹果与核果，有时带白胡椒，不甜、高酸度、中等至饱满酒体。品酒单元与理论分开评分，所以定期用真实酒款练习是最好的准备方式。

如果 WSET Level 3 理论通过、品酒没过，会怎样？

理论与品酒是两个独立单元，每个都至少需要 55%。如果其中一个没过，只需重考该单元；已通过的单元会保留。正因如此，盲品值得用和理论一样认真的态度准备，而不是指望理论成绩够好就能过关。

Ausbruch 和 Trockenbeerenauslese 有什么不同？

两者都是以贵腐葡萄酿成的甜酒。Ausbruch 是奥地利的传统等级，与新锡德尔湖畔的鲁斯特镇相关，葡萄汁糖度介于 Beerenauslese 与 Trockenbeerenauslese 之间。Trockenbeerenauslese 是最高的 Prädikat 等级，以逐粒挑选、糖分极高的萎缩果粒酿成。考试时记住：Ausbruch 就位在 TBA 的下一级。

在 WSET Level 3 题目中，哪个奥地利产区应该和红葡萄酒联想在一起？

布尔根兰是关键的红葡萄酒产区，因为它是奥地利最温暖的地方。中布尔根兰以颜色深、酸度高、单宁扎实、带黑樱桃与香料风味的 Blaufränkisch 闻名。Zweigelt 是奥地利种植最多的黑葡萄，分布广泛，酿出较柔和、果香更丰富的酒。施泰尔马克则较以 Sauvignon Blanc 著称。
