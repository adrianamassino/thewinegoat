学习笔记：WSET Level 3 勃艮第与博若莱

WSET Level 3 的勃艮第题目反复考三件事：凉爽的大陆型气候如何塑造黑皮诺与霞多丽、法定产区分级如何运作，以及为什么相邻的两个区喝起来不一样。这份学习笔记是一份精简的勃艮第与博若莱复习指南，写法就跟考试评分的逻辑一样：先原因，再结果，最后是风格。读过一遍后，再用上面的示例题目检查自己记住了多少。

气候：为什么勃艮第处于边缘

勃艮第属于凉爽的大陆型气候：冬季寒冷、夏季温暖，生长季相当短。由于这里接近黑皮诺与霞多丽能够成熟的极限，年份差异很大。两个品种都很早发芽，因此春霜是真正的威胁，尤其是在最凉爽、最北端的 Chablis。夏季冰雹可能在几分钟内毁掉一个村庄的大部分收成，而采收前后的降雨则会提高皮薄的黑皮诺发生腐烂的风险。好的答案会把每项风险与其后果联系起来：霜害与冰雹会降低产量，采收期的雨水会稀释风味并使灰霉菌扩散，凉爽的年份则会让酒的酸度偏高、酒体偏轻。

金丘（Côte d'Or）的坡度、坡向与土壤

金丘是一道朝东与东南方向延伸的长断崖。最好的葡萄园位于坡地中段，因为这里早上能获得更多日照，背后的山丘能挡住凉爽的西风，薄薄的石灰岩与泥灰岩土壤排水良好，而且较不容易遭受霜害，因为冷空气会往下流到下方的平地。坡脚的葡萄园土壤较深厚、肥沃，通常酿成村庄级或地区级酒款。往上到上丘区（Hautes-Côtes），气候更凉、更暴露，因此酒较轻盈、清瘦。

在 WSET Level 3 的勃艮第单元，你应该能由北到南指出每个分区的位置，并说出它以哪个品种和风格闻名。把它们当成沿着地图往南的一趟旅程来记。

Chablis：凉爽、易受霜害、带矿物感

Chablis 比金丘凉爽，因此这里的霞多丽酸度更高、酒体更轻，带有绿色水果风味。特级园集中在小镇与 Serein 河上方一片朝西南的坡地上，能获得更多日照。防霜是 Chablis 题目的核心：葡萄种植者会在葡萄树间放置加热器或蜡烛，并使用洒水系统，让芽苞包覆一层冰，冰在凝结时释放潜热，使芽苞维持在冰点左右，而不会降到冰点以下。许多酒厂以不锈钢槽发酵来保留纯净的果味；部分一级园与特级园酒款会使用橡木桶，但通常新桶比例不高。

夏隆内丘与马孔内

金丘以南的山丘不再连绵，因此葡萄园较分散，酒款一般较轻盈、价格也较低。Montagny 只产白葡萄酒，而 Bouzeron 是唯一以阿里高特为主的村庄级法定产区。马孔内更温暖，因此霞多丽更成熟、酸度较低，带有更多哈密瓜与核果风味；大部分由合作社大量生产，而 Pouilly-Fuissé 与 Saint-Véran 则可能经橡木桶陈年，风味浓缩、质量严谨。

勃艮第法定产区分级解析

勃艮第分级的对象是葡萄园，而不是酒厂。每往上一级，对葡萄生长地点的规范就越精确；一般而言，每升一级供应量就减少，价格也随之上升。

  1. 地区级法定产区：Bourgogne（以及 Bourgogne Aligoté、Crémant de Bourgogne 等变化）。葡萄可以来自产区内任何地方。
  2. 村庄级法定产区：来自单一指定村庄的酒，例如 Meursault 或 Gevrey-Chambertin。
  3. 一级园（Premier Cru）：村庄内质量较优、有名称的葡萄园；酒标会标示村庄名、葡萄园名，以及 Premier Cru 或 1er Cru。
  4. 特级园（Grand Cru）：最顶尖的指定葡萄园，只占产量的一小部分。酒标只标示葡萄园名，例如 Chambertin、Richebourg 或 Montrachet。

WSET Level 3 的勃艮第题目还常出现另外两个观念。第一，许多知名村庄把自己最好的特级园名称加到村名后面（Gevrey 变成 Gevrey-Chambertin），所以村庄级酒款也可能带有特级园的名字。第二，葡萄园的所有权极度分散，因为继承法把葡萄园分给了各个继承人。像 Clos de Vougeot 这样的一个特级园就可能有数十位地主。这说明了酒商（négociant）的重要性：他们向许多葡萄种植者收购葡萄、葡萄汁或葡萄酒再加以混酿；也说明了酒庄（domaine）的重要性：酒庄以自有葡萄园的葡萄酿酒并装瓶。完全由单一酒庄拥有的葡萄园称为独占园（monopole）。

考试技巧：如果简答题问同一年份的两款勃艮第为什么不同，至少要说出三个因素：地块（坡地位置、坡向、土壤）、法定产区的等级，以及酒厂的决定（产量、整串发酵、新橡木桶）。像“风土不同”这种笼统说法几乎拿不到分数。

勃艮第的酿造：黑皮诺与霞多丽

勃艮第红葡萄酒

黑皮诺皮薄，颜色与单宁相对较少，因此酿酒师会以温和的方式萃取。常见做法包括：发酵前低温浸渍，萃取颜色与果味而不带出单宁；以部分或全部整串葡萄发酵，增添清新的草本与辛香气息，使风格更轻盈、更芬芳；以压帽取代强力的淋汁。高级酒款会在橡木桶中熟成，通常只使用部分新桶，以免盖过果味。随着陈年，红色水果会转变为泥土、蘑菇、森林地表与野味的气息。

勃艮第白葡萄酒

高级勃艮第白葡萄酒是橡木桶发酵霞多丽的典范。在桶中发酵与熟成能带来烤面包与香草风味，而且比单纯桶陈更能让橡木风味融合；乳酸转换柔化酸度并增添奶油香；酒泥接触与搅桶则增加酒体，带来饼干般的奶油质地。这些技术与地块天然酸度之间的平衡，决定了酒的风格。Puligny-Montrachet 常被形容为更细致、更有矿物感，Meursault 则更丰厚、带坚果香：这是应付选择题很好用的简记法。

博若莱：佳美、花岗岩与二氧化碳浸渍法

博若莱位于马孔内以南，比勃艮第其他地方温暖。这里的品种是佳美（Gamay），酿出的酒酸度高、单宁低到中等，带樱桃、覆盆子和草莓等红色水果风味。传统的葡萄树采杯型整枝并以人工采收，这点很重要，因为二氧化碳浸渍法与半二氧化碳浸渍法需要完整、未破损的葡萄串。半二氧化碳浸渍法能萃取颜色而只带出少量单宁，并增添香蕉、樱桃白兰地和泡泡糖的香气，这就是为什么简单的博若莱柔和、果味丰富，最适合趁年轻饮用。

Beaujolais、Beaujolais-Villages 与十个特级村

产区南部土壤是较肥沃的黏土与石灰岩，主要生产基本款 Beaujolais，包括在采收后于十一月第三个星期四上市的 Beaujolais Nouveau。北部是花岗岩丘陵，生产 Beaujolais-Villages 与十个特级村（cru）：Saint-Amour、Juliénas、Chénas、Moulin-à-Vent、Fleurie、Chiroubles、Morgon、Régnié、Brouilly 与 Côte de Brouilly。Fleurie 与 Chiroubles 通常较轻盈、芬芳；Moulin-à-Vent 与 Morgon 结构最扎实、能够陈年，有时以传统发酵和橡木桶酿造，因此随着时间可能喝起来更像黑皮诺。

简答题范例：为什么葡萄园在金丘的位置很重要

题目：请解释为什么金丘最好的葡萄园通常位于坡地中段。（参考答案）

金丘属于凉爽到温和的大陆型气候，葡萄不一定能成熟，因此地块的细微差异对质量影响很大。坡地中段面向东方与东南方，葡萄树能接收早晨的阳光，整体日照也更多，有助于葡萄完全成熟。坡地提供良好的排水，这里的土壤是比例均衡的石灰岩与泥灰岩，既不过于肥沃也不过于贫瘠，能抑制树势与产量，使风味更浓缩。

在坡脚，土壤更深厚、更肥沃，排水较差，因此产量较高、葡萄较不浓缩；冷空气也会聚积在那里，提高霜害风险。在坡顶，土壤很薄，葡萄树更容易受冷风吹袭，因此较难成熟。这就是为什么特级园与一级园集中在坡地中段，而村庄级与地区级酒款则来自下方较平坦的土地。

勃艮第与博若莱的常见错误

  • 写所有勃艮第白葡萄酒都经过橡木桶：Chablis 与基本款 Mâcon 常常不过桶。
  • 把 Pouilly-Fuissé 放在卢瓦尔河：它位于马孔内（Pouilly-Fumé 才是卢瓦尔河的长相思）。
  • 忘了特级园酒标只标示葡萄园名，不标村庄名。
  • 说博若莱特级村只用二氧化碳浸渍法酿造：许多是用半二氧化碳浸渍法或传统法酿造，有些还会经橡木桶陈年以延长陈年潜力。
  • 把夜丘（以红葡萄酒为主）和伯恩丘（白葡萄酒与红葡萄酒都很有名）搞混。
  • 忽略年份差异：在边缘气候中，天气说明了不同年份之间的差异。

品酒单元中的勃艮第与博若莱

记住，在 Level 3 中理论与品酒是两个独立单元：每个单元都需要至少 55%，没通过的单元可以单独重考。黑皮诺与佳美是品酒练习的常客，因为它们考验你对颜色、酸度和单宁的判断。勃艮第红葡萄酒通常呈浅到中等的宝石红色，带红色水果（樱桃、覆盆子），酸度高、单宁低到中等；陈年的酒款则呈石榴红，带蘑菇与森林地表的气息。博若莱常呈紫红色，红莓果香非常浓郁，有时带有二氧化碳浸渍法带来的香蕉或泡泡糖气息，酸度高、单宁低。

要写出好的质量结论，就要说明果味、酸度和单宁之间的平衡，以及尾韵的长度。对黑皮诺来说，颜色浅并不代表质量低；准确描述你看到和尝到的，并把适饮程度与果味强度及三级香气的有无联系起来。

如何从勃艮第酒标分辨特级园与一级园？

特级园酒标通常只标示葡萄园名，例如 Chambertin 或 Montrachet，再加上 Grand Cru。一级园酒标则标示村庄名，后面接葡萄园名以及 Premier Cru 或 1er Cru 字样，例如 Meursault 1er Cru Perrières。如果酒标只标示村庄名，就是村庄级酒款。

WSET Level 3 要知道的十个博若莱特级村是哪些？

十个特级村大致由北到南是 Saint-Amour、Juliénas、Chénas、Moulin-à-Vent、Fleurie、Chiroubles、Morgon、Régnié、Brouilly 与 Côte de Brouilly。它们都位于产区北部的花岗岩地带。Moulin-à-Vent 与 Morgon 最饱满、最耐陈年；Fleurie 与 Chiroubles 较轻盈、花香较明显。

为什么 Chablis 和金丘的霞多丽不同？

Chablis 位置更北、更凉爽，所以霞多丽的成熟度较低：酸度更高、酒体更轻，带青苹果与柑橘风味。许多酒厂使用不锈钢槽或旧橡木桶来保留这种清新纯净的风格，而金丘的高级白葡萄酒通常在橡木桶中发酵与陈年，并使用部分新桶，果味更成熟，烤面包香与奶油质地也更明显。

在 WSET Level 3 课程大纲中，博若莱属于勃艮第吗？

为了学习方便，博若莱会和勃艮第归在一起，因为它就位于马孔内以南，也常与勃艮第一并讨论。不过它的气候、花岗岩土壤、佳美品种以及二氧化碳浸渍法的运用，让它的酒相当不同，所以要把它当成一个独立产区来复习，并记住它自己的分级：Beaujolais、Beaujolais-Villages 与十个特级村。

在 WSET Level 3 的答案中，如何比较 Chablis 和 Meursault？

从气候开始：Chablis 位置更北、更凉爽，所以霞多丽保有高酸度，呈现青苹果与柑橘风味。伯恩丘的 Meursault 成熟度更高，果味更成熟、酒体更饱满。接着加入酿造：Chablis 常不过桶，而 Meursault 通常在橡木桶中发酵与陈年，搅桶与乳酸转换带来坚果与奶油气息。

WSET Level 3 需要认识夏隆内丘的哪些产区？

记住 Rully、Mercurey、Givry 与 Montagny。Rully 以白葡萄酒和起泡酒基酒闻名，Mercurey 与 Givry 主要产红葡萄酒，Montagny 只产白葡萄酒。Bouzeron 是阿里高特的法定产区。这些酒的风格与金丘相似，但通常更轻盈、浓缩度较低，而且物超所值。

为什么霜害是 Chablis 的主要风险？

Chablis 属于凉爽的大陆型气候，春季寒冷，萌芽后的霜害可能伤及嫩梢，造成减产。葡萄种植者会在行间放置加热器或蜡烛，并使用洒水系统让芽苞包覆一层冰；水结冰时会释放热量，使芽苞温度维持在接近零度。

博若莱特级村能陈年吗？

有些可以。Moulin-à-Vent 与 Morgon 等特级村可能采用较长的浸渍时间，有时还会经橡木桶陈年，使结构更扎实，让酒能发展好几年，并出现可能令人联想到黑皮诺的咸香气息。Fleurie 或 Chiroubles 等较轻盈的特级村通常最适合趁年轻饮用，那时花香与红色水果香气最鲜明。

勃艮第在 WSET Level 3 品酒单元中会如何出现？

理论与品酒是独立的单元，各需至少 55%。品酒时你可能要评估一款黑皮诺或霞多丽，但不会被要求说出它是什么酒。你要运用系统品酒法描述外观、香气与口感，并对质量与适饮期做出合乎逻辑的结论。准确判断酸度与单宁等级，比猜中产地更重要。
