1 德国大多数葡萄酒产区属于哪一种气候？

显示答案

答案：凉爽大陆性气候

解析：南部的巴登（Baden）明显较温暖。漫长而凉爽的成熟期能累积糖分，同时保留酸度。

2 德国最陡峭的坡地上，葡萄树采用哪种整枝方式？

显示答案

答案：头状修剪，每株单独立桩，枝条绑在桩顶

解析：这种方式能让日照与通风达到最大。

3 德国种植面积最广的葡萄品种是哪一个？

显示答案

答案：雷司令（Riesling）

解析：风格从干型到浓郁甜美、从花香到更丰富的桃子风味都有；最好的干型酒款常是 Grosses Gewächs。

4 Prädikat 等级应该如何理解？

显示答案

答案：作为风格指标

解析：几乎所有等级都可能带有残糖，但到 Auslese 为止的等级也可以是干型的。

5 甜型 Kabinett 的酒精度通常是多少？

显示答案

答案：8-9% abv

解析：偏干的酒款可达 12%。Kabinett 是最细致的 Prädikat：轻盈、高酸，带青苹果与柑橘风味。

6 同一产区的 Spätlese 与 Kabinett 有什么不同？

显示答案

答案：更浓缩、更成熟，酒体、酒精度与甜度都稍高一些

解析：酿造方式与 Kabinett 相同；雷司令 Spätlese 常带柑橘与核果风味。

学习笔记：WSET Level 3 德国

WSET Level 3 的德国题目考三件事：为什么凉爽气候也能让葡萄成熟、主要产区在风格上有什么不同，以及如何解读德国酒标。如果你能用因果关系解释这三点，几乎任何德国选择题与大多数简答题都难不倒你。这些笔记就是上面示例题目背后的复习指南。

气候：凉爽的大陆性国家如何让雷司令成熟

德国是全世界纬度最高的优质葡萄酒产国之一，因此大多数产区属于凉爽大陆性气候，冬季寒冷、夏季温暖，秋季漫长而缓慢。只有在葡萄园的地点能提供额外温暖的地方，葡萄才会完全成熟。这就是为什么选址是德国葡萄栽培最重要的单一因素，也是为什么德国的考试答案一定要提到坡向、坡度与河流。

  • 陡峭的南向坡能以更直接的角度接收低斜的阳光，让葡萄获得更多热能与光照。
  • 莱茵河（Rhine）、摩泽尔河（Mosel）、美因河（Main）与纳赫河（Nahe）等河流能调节气温、降低霜害风险，并把阳光反射到葡萄树上。
  • 摩泽尔深色的板岩土壤白天吸收热能、夜间释放，有助于葡萄成熟。
  • 森林与山丘，例如莱茵高（Rheingau）上方的陶努斯山（Taunus）与普法尔茨（Pfalz）的哈特山脉（Haardt），为葡萄园挡住冷风与雨水。
  • 漫长而凉爽的成熟期能累积糖分与香气，同时保留非常高的酸度：这正是德国雷司令的招牌特色。

在简答题中，绝对不要只写“凉爽气候”。要写出完整的因果链：凉爽大陆性气候，所以需要靠近河流的陡峭南向坡才能让葡萄成熟，所以酒能保有高酸度与明显的果味，酒精度通常为低至中等。

WSET Level 3 德国产区：摩泽尔、莱茵高、普法尔茨等

德国有 13 个优质葡萄酒产区（Anbaugebiete）。在 WSET Level 3，你需要掌握的是主要产区的特色，而不是每个村庄的地图。关键在于把每个产区联系到它的气候、土壤与典型风格。

产区主要特色典型风格
摩泽尔（含萨尔 Saar 与鲁文 Ruwer）沿着蜿蜒河道的极陡板岩坡；最凉爽的产区之一酒体轻盈的雷司令，高酸、低酒精，常见微甜或甜型的 Kabinett 与 Spätlese；也有干型酒款

立即注册

葡萄品种：雷司令、米勒-图高、Spätburgunder

雷司令（Riesling）

雷司令是德国种植最广、也最重要的葡萄品种。它晚熟，木质坚硬而耐霜冻，即使完全成熟也能保持高酸度。它能强烈展现地块特色，可以酿出从极干到浓郁甜美的各种风格。年轻的酒带有青苹果、柑橘、白花香气，在较成熟的地块还有桃子与杏子风味。经过瓶中陈年，优质雷司令会发展出蜂蜜、烤面包与汽油的气息。由于它是芳香型品种，风味来自品种本身与地块，因此通常不使用新橡木桶，也不进行乳酸转化。

米勒-图高与西万尼

米勒-图高早熟、产量高，因此曾大量种植在条件较差的地块。它酿出轻盈、柔和、简单的酒，酸度低至中等，通常适合早饮。西万尼香气中性，但在弗兰肯表现最好，能酿出干型、中等酒体、带土壤与草本特色的酒。

Spätburgunder 与皮诺家族

Spätburgunder 是黑皮诺（Pinot Noir）的德文名称，也是德国种植最多的黑葡萄。气候变暖与更好的克隆大幅提升了质量：最好的酒来自巴登、普法尔茨与阿尔，有时会在新橡木桶中陈年。Grauburgunder（灰皮诺）与 Weissburgunder（白皮诺）能酿出干型、较饱满的白葡萄酒，尤其在巴登与普法尔茨。丹菲特（Dornfelder）是一种黑葡萄，能酿出颜色深浓、果味丰富的红葡萄酒。

酿造：残糖、Süssreserve 与干型风格

德国的酿酒目标是保留果味与酸度。通常在不锈钢槽或不会增添橡木风味的大型老橡木桶中低温发酵。甜度与高酸度相互平衡，这就是为什么一款明显带糖的德国雷司令喝起来仍然清新而不腻口。

  1. 中止发酵：酿酒师将酒冷却并以过滤去除酵母，留下天然残糖与较低的酒精度（摩泽尔 Kabinett 的典型做法）。
  2. Süssreserve：在装瓶前将未发酵的葡萄汁加入已完全发酵的干型酒中以调整甜度，主要用于平价酒。
  3. 发酵至干：酒发酵到干，酒精度较高；标示为 trocken。
  4. 在凉爽的年份，Qualitätswein 允许加糖（chaptalisation），但 Prädikatswein 不允许。
  5. 在非常凉爽、酸度过高的年份，可以进行降酸。

德国酒标：Qualitätswein、Prädikatswein 与 VDP

德国葡萄酒法依产地与采收时葡萄的成熟度（葡萄汁比重，must weight）为酒分级。Deutscher Wein 没有地理标志，Landwein 属于 PGI，Qualitätswein 与 Prädikatswein 则属于 PDO。Qualitätswein 必须来自 13 个产区之一。Prädikatswein 还必须达到最低葡萄汁比重，而且不得加糖。

Prädikat 等级采收的葡萄典型风格
Kabinett最轻盈、成熟度最低的 Prädikat轻盈、细致、高酸；干型、微甜或甜型
Spätlese晚摘，成熟度更高酒体与浓缩度更高；干型或甜型
Auslese精选非常成熟的葡萄串，有时带贵腐菌浓郁，常为甜型，但也可能干型
Beerenauslese（BA）逐粒精选的过熟果粒，通常受贵腐菌影响浓郁甜美，带蜂蜜风味
Trockenbeerenauslese（TBA）干缩的贵腐果粒极甜、浓缩，寿命极长，酒精度低
Eiswein（冰酒）葡萄在树上结冻，并在结冻状态下压榨非常甜，带尖锐的酸度，通常没有贵腐菌

VDP 是顶级酒庄组成的协会，采用自己的葡萄园分级：Gutswein、Ortswein、Erste Lage 与 Grosse Lage。Grosses Gewächs 是来自 Grosse Lage 地块的干型酒。酒标上也可能出现 trocken（干型）、halbtrocken 或 feinherb（微甜）。

常见错误：以为所有 Prädikat 酒都是甜的。Prädikat 衡量的是采收时的成熟度，而不是瓶中的甜度。Spätlese trocken 就是干型的。只有 BA、TBA 与 Eiswein 一定是甜的。

简答题范例：摩泽尔雷司令

考试风格题目：解释为什么摩泽尔雷司令 Kabinett 酒体轻盈、酸度高、酒精度低。高分答案：摩泽尔属于凉爽大陆性气候，因此葡萄成熟缓慢，保留了高酸度。葡萄园位于靠近河流的陡峭南向板岩坡上，提供刚好足以让雷司令成熟的温暖。Kabinett 使用成熟度最低的 Prädikat 葡萄，因此糖分适中。发酵常以冷却与过滤提早中止，留下残糖与较低的酒精度。雷司令是芳香型品种，因此不使用新橡木桶，保留了明显的柑橘与青苹果果味。

德国在 WSET Level 3 两个单元中的角色

WSET Level 3 分为两个独立单元。理论单元包含 50 题选择题与 4 题简答题；品酒单元则要你用系统品酒法（SAT）盲品评鉴两款酒。每个单元都必须达到至少 55%，分开评分，没通过的单元单独重考即可。德国是理论考试的常见主题，因为它结合了以地块为核心的葡萄栽培、精确的标示制度，以及成熟度与风格之间清楚的关联。

德国雷司令也是品酒单元最实用的练习酒款之一，即使考试永远不会要你说出它的名字。它能训练考生常判断错误的两件事：把甜度与果味区分开来，以及在残糖柔化口感时正确评估高酸度。一款明显带糖的 Kabinett 仍然可能是高酸、酒体轻盈、酒精度低，而你的笔记就应该准确写出这一点。

逐步解读德国酒标

以我们自己虚构的酒标为例：Mosel、Riesling、Spätlese、trocken。分四个步骤阅读，你就能在品尝之前描述这款酒。

  1. 产区：摩泽尔，最凉爽的产区之一，有陡峭的板岩坡；预期酸度高、酒体轻盈至中等。
  2. 品种：雷司令，芳香、晚熟、酸度高，带柑橘、青苹果与核果风味。
  3. Prädikat：Spätlese，代表葡萄采收时比 Kabinett 更成熟；预期浓缩度与酒体更高。
  4. 甜度用语：trocken，代表酒发酵到干；预期口感干型，酒精度比甜型 Spätlese 高。

Prädikat 告诉你葡萄有多成熟；trocken、halbtrocken 或 feinherb 这些字则告诉你酒有多甜。两者都读过之后，再判断风格。

德国干型、微甜与甜型葡萄酒比较

酒标标示甜味典型酒精度应用范例
Trocken干型以德国而言属中等至高普法尔茨或莱茵高的干型雷司令；Grosses Gewächs
Halbtrocken 或 feinherb微甜中等以高酸度平衡些微甜味的雷司令
没有干型用语的 Kabinett 或 Spätlese通常为微甜至中甜低以中止发酵酿造的经典摩泽尔风格
BA、TBA、Eiswein一定是甜型至浓郁甜美低以贵腐或结冻葡萄酿成的稀有甜点酒

附解析的练习题

第 1 题：为什么 Prädikatswein 不得加糖？答案：Prädikat 制度依采收时葡萄的天然成熟度为酒分级。加糖会提高酒精度并掩盖真正的葡萄汁比重，与这个等级的意义相矛盾。

第 2 题：为什么莱茵高雷司令通常比摩泽尔雷司令更饱满？答案：莱茵河在那里由东向西流，形成绵长的南向坡，而陶努斯山为葡萄园挡住北方的冷风。额外的温暖让葡萄更成熟、酒体更饱满，同时酸度依然很高。

第 3 题：冰酒（Eiswein）如何酿造？为什么它的酸度这么高？答案：健康的葡萄留在树上直到严重霜冻，然后在结冻状态下采收并压榨。大部分的水分以冰的形式留下，因此葡萄汁中的糖分与酸度同时被浓缩，酿出非常甜、带尖锐酸度的酒。

第 4 题：为什么德国 Spätburgunder 的质量进步这么多？答案：较温暖的生长季帮助葡萄完全成熟，种植了更好的克隆，许多生产者的酿造也更讲究，包括为巴登、普法尔茨与阿尔的顶级酒款采用橡木桶熟成。

德国葡萄酒术语表

  • Anbaugebiet：德国 13 个优质葡萄酒产区之一。
  • 葡萄汁比重（must weight）：采收时葡萄汁的含糖量，是 Prädikat 等级的基础。
  • Trocken：干型。Halbtrocken 与 feinherb：微甜。
  • Lage：单一葡萄园地块；在 VDP 制度中，Erste Lage 与 Grosse Lage 是最高等级。
  • Süssreserve：装瓶前加入以调整甜度的未发酵葡萄汁。
  • Bocksbeutel：弗兰肯传统使用的扁圆形酒瓶。

重要。50 题选择题涵盖整份课纲，4 题简答题则常聚焦于某个产区或工艺，因此包括德国在内的每个主题都有可能出现。

对 WSET Level 3 而言，哪些德国产区最重要？

重点放在摩泽尔、莱茵高、普法尔茨、莱茵黑森、纳赫、巴登与弗兰肯。你应该能把每个产区联系到它的气候与典型风格，例如摩泽尔对应轻盈、低酒精、常带甜味的雷司令，普法尔茨对应更饱满的干型雷司令，巴登对应 Spätburgunder，弗兰肯则对应装在 Bocksbeutel 瓶中的西万尼。

WSET Level 3 要求的德国 Prädikat 等级顺序是什么？

依采收时成熟度由低到高：Kabinett、Spätlese、Auslese、Beerenauslese、Trockenbeerenauslese。Eiswein 另成一类，以自然结冻的葡萄酿成，最低葡萄汁比重与 Beerenauslese 相当。记住这些等级描述的是葡萄的成熟度，而不是瓶中的甜度。

德国葡萄酒的 Süssreserve 是什么？

Süssreserve 是在装瓶前加入已发酵干型酒中、用来增加甜度的未发酵葡萄汁，主要用于平价德国酒。优质生产者更常以冷却与过滤中止发酵，保留天然残糖与较低的酒精度。

德国酒标上的 Grosses Gewächs 是什么意思？

Grosses Gewächs 是 VDP 会员酒庄使用的用语，指来自 Grosse Lage（他们最高等级的葡萄园类别）的干型酒。它是顶级干型酒的质量与风格指标，最常见的是雷司令，但 Spätburgunder 与其他品种也可以这样标示。

为什么德国雷司令即使是甜的，喝起来仍然清新？

德国雷司令生长在凉爽气候中，因此保有非常高的酸度。这份酸度平衡了残糖，让甜型 Kabinett 或 Spätlese 喝起来活泼而不厚重。糖与酸之间的平衡，是 WSET Level 3 品酒与理论答案中的经典考点。

德国雷司令会出现在 WSET Level 3 的品酒单元吗？

课纲范围内的任何酒都可能被使用，但品酒单元从不要求你辨识酒款。评分依据是精确的 SAT 描述与有根据的结论，这个单元与理论分开评分，有自己的 55% 及格门槛。德国雷司令是理想的练习酒款，因为它考验你分别判断酸度与甜度的能力。

trocken 与 feinherb 有什么不同？

Trocken 表示酒是干型的：发酵几乎耗尽了所有糖分。Feinherb 和 halbtrocken 一样，表示带少许残糖的微甜酒。在德国雷司令中，高酸度常让微甜酒喝起来比实际含糖量更清新、更干，这也是为什么这些用语能帮你预测酒的平衡。

如何快速解读德国酒标？

分四个步骤阅读：产区告诉你气候，品种告诉你香气与结构，Prädikat 告诉你葡萄有多成熟，而 trocken 或 feinherb 等字告诉你甜度。Kabinett 或 Spätlese 的酒标上若没有干型用语，通常表示酒带有一些残糖。

为什么冰酒的酸度这么高？

冰酒以在树上结冻、并在结冻状态下压榨的葡萄酿成。水分以冰的形式留下，因此流出的葡萄汁中糖分与酸度同时被浓缩。由于葡萄通常是健康的、没有受到贵腐菌影响，酒展现纯净的果味，极高的甜度由尖锐的酸度平衡。

德国的复习时间该如何分配在两个单元之间？

主要把德国当作理论主题：产区、Prädikat 顺序、甜型酒的酿造，以及酒标用语，用于选择题与简答题。同时，在品酒练习中加入干型与微甜的雷司令。由于两个单元分开通过，保持均衡的计划，不要让任何一个单元落后。
