练习题与解答（The Wine Goat 题库）

1 哪三个希腊品种在国外最有知名度？分别来自哪里？

显示答案

答案：Xinomavro（Naoussa）、Agiorgitiko（Nemea）、Assyrtiko（Santorini）

解析：希腊有超过 200 个适应炎热气候的原生品种；大多数 PDO 葡萄酒都必须使用原生品种。

2 Naoussa PDO 使用哪个品种酿造？

显示答案

答案：只用 Xinomavro

解析：Naoussa 位于马其顿（Macedonia），葡萄园海拔最高到 400 米，比周边地区凉爽。这是一个红葡萄酒 PDO。

3 Xinomavro 常被拿来和哪个品种比较？

显示答案

答案：内比奥罗（Nebbiolo）

解析：单宁与酸度高，颜色中等且很快转为黄褐色，新鲜果味不多；陈年潜力长，会发展出辛香料与泥土气息。

4 Nemea 位于哪里？使用哪个品种？

显示答案

答案：位于伯罗奔尼撒半岛北部，只用 Agiorgitiko

解析：葡萄园海拔介于 230-900 米；最好的位于中段。低处的酒带果酱风味；高处的酒酸度较高，最适合酿桃红葡萄酒。

5 希腊：法定产区／品种

显示答案

答案：Naoussa／Xinomavro

解析：Naoussa = Xinomavro；Nemea = Agiorgitiko；Santorini = Assyrtiko。

6 即使在较潮湿的希腊西部，为什么葡萄树仍可能遭受缺水压力？

显示答案

答案：因为生长季几乎不下雨

解析：地中海型气候：雨水落在冬季，夏季几乎无雨。

学习笔记：WSET Level 3 希腊

WSET Level 3 的希腊题目篇幅短、可预测：考的是地中海型气候，以及海拔与海风如何调节它、少数几个原生品种，还有每个品种与其法定产区之间的联系。希腊在课程大纲中是个小主题，只要记住重点配对，并能用因果关系加以解释，就很容易拿分。这份笔记就是上面示例题目背后的复习指南。

气候：炎热干燥的夏季，由海拔与海洋调节

希腊属于地中海型气候：夏季炎热干燥，冬季温和多雨。生长季几乎不下雨，因此即使在较潮湿的西部，干旱与缺水压力也是真实的风险。品都斯山脉（Pindus）纵贯中部，挡住来自爱奥尼亚海的雨水，所以西部较潮湿、东部较干燥。希腊北部，尤其是马其顿，比南部与岛屿更凉爽、更偏大陆型气候。

  • 海拔能让葡萄园降温：许多优质地块种在坡地与高原上，以减缓成熟速度并保留酸度。
  • 来自爱琴海与爱奥尼亚海的海风，调节沿海与岛屿的温度。
  • 强风，例如爱琴海诸岛的夏季季风，能为葡萄树降温，但也可能损伤新梢、降低产量。
  • 夏季雨量少代表真菌病害少，但常需要灌溉或采用耐旱的整枝方式。
  • 大多数原生品种都很能适应炎热与干旱，这也是希腊倚重它们的原因之一。

在希腊葡萄酒的简答题中，一定要加上调节因素。光是“炎热的地中海型气候”只能解释成熟度与酒精度，却无法解释清新感。应该这样写：气候炎热，但葡萄园位于高海拔或靠近海洋，所以夜晚较凉、成熟较慢，因此酒能保留酸度。

WSET Level 3 要认识的希腊葡萄品种

希腊有超过 200 个原生葡萄品种。在 WSET Level 3 中，你只需要掌握一小群，最重要的是在国外最有知名度的三个：Assyrtiko、Agiorgitiko 与 Xinomavro。赤霞珠、梅洛、西拉和霞多丽等国际品种也有种植，常用于 PGI 葡萄酒，有时会与原生品种混酿。

Assyrtiko

Assyrtiko 是希腊的旗舰白葡萄品种。它最重要的特质是即使在炎热气候中也能保有非常高的酸度，因此能在烈日曝晒的岛屿上酿出清新、有结构的酒。它带有柠檬、葡萄柚等柑橘风味，常有石头般的矿物感。它可以在不锈钢槽中酿造以保留清新感，也可以在橡木桶中陈年以增加质地，最好的酒款会随瓶中陈年持续发展。它也用来酿造甜酒。

Agiorgitiko

Agiorgitiko 是伯罗奔尼撒半岛最重要的黑葡萄品种，也是 Nemea 红葡萄酒唯一允许使用的品种。它用途广泛：可以酿成桃红葡萄酒、单宁柔和并带红樱桃与李子风味的轻盈未过桶红葡萄酒，或带甜香料气息、更丰厚的橡木桶陈年红葡萄酒。风格在很大程度上取决于海拔，详见下文。

Xinomavro

Xinomavro 是希腊北部最主要的黑葡萄品种。它的名字意思是“酸的黑色”，这是很好用的线索：它酸度高、单宁高，颜色却只有中等，而且很早就出现黄褐色调。它常被拿来和内比奥罗比较。年轻的酒带红樱桃与覆盆子，以及番茄和橄榄的气息；随着陈年，最好的酒会发展出果干、辛香料与泥土风味。由于结构强劲，它需要陈年，常在橡木桶中熟成，并能陈放多年。

立即注册

希腊重要法定产区：Naoussa、Nemea、Santorini、Mantinia

大多数希腊 PDO 葡萄酒都必须以原生品种酿造，这就是考试会把每个法定产区与单一品种联系起来的原因。把这些配对当成一组来记：Naoussa 与 Amyndeon 配 Xinomavro，Nemea 配 Agiorgitiko，Santorini 配 Assyrtiko，Mantinia 配 Moschofilero。

Naoussa 与 Amyndeon（马其顿）

Naoussa PDO 位于希腊北部的马其顿，只以 Xinomavro 酿造红葡萄酒。由于纬度偏北、葡萄园位于山坡，这里的气候比南部凉爽，因此葡萄能保有高酸度与扎实的单宁。Amyndeon 海拔更高、更凉爽；那里的 Xinomavro 也会酿成桃红葡萄酒与起泡酒，高酸度反而成为优势。

Nemea（伯罗奔尼撒半岛）

Nemea PDO 位于伯罗奔尼撒半岛北部，只以 Agiorgitiko 酿造红葡萄酒。葡萄园的海拔范围很广，这会改变酒的风格：低处温暖的地块酿出成熟、带果酱风味的柔和酒款；中海拔地块通常被认为在成熟度与清新感之间取得最佳平衡；最高、最凉爽的地块则酿出酸度较高、较轻盈的酒，适合做桃红葡萄酒。

Santorini（爱琴海岛屿）

Santorini PDO 是爱琴海上一座以 Assyrtiko 闻名的火山岛。这里雨量极少、风势强劲。火山砂质土壤贫瘠，根瘤蚜无法在其中存活，因此许多葡萄树非常古老，而且没有嫁接。为了保护葡萄不受强风与风沙侵袭，葡萄树传统上贴地整成低矮的篮状（koulara）。产量非常低，酿出的酒风味浓缩、酸度高、酒体饱满，带柑橘与矿物风味。Santorini 也生产 Vinsanto，这是一种以日晒风干葡萄（主要是 Assyrtiko）酿成、并在橡木桶中长时间陈年的甜酒。

Mantinia（伯罗奔尼撒半岛）

Mantinia PDO 是伯罗奔尼撒半岛中部的一片高原，也是希腊南部较凉爽的种植地之一。这里以 Moschofilero 酿造白葡萄酒：酒体轻盈、酸度高，带明显的花香与葡萄香气。海拔说明了为什么它虽然位于南方纬度，仍能保有清新感。

简答题范例：Santorini 的 Assyrtiko

考试风格题目：请解释气候、土壤与葡萄栽培如何影响 Santorini Assyrtiko 的风格。应包含的要点：

  1. 炎热干燥的地中海型气候，雨量极少，因此葡萄能完全成熟，但水分稀缺。
  2. 强风为葡萄树降温，但也可能造成损伤，因此葡萄树以低矮的篮状整枝，保护新梢与果串。
  3. 火山土壤贫瘠、肥力低，因此产量非常低，酒的风味浓缩。
  4. 根瘤蚜无法在砂质土壤中存活，因此许多葡萄树古老且未嫁接，进一步增加浓缩度。
  5. Assyrtiko 天生能在炎热中保有高酸度，因此酒体饱满却依然清新，带柑橘与石头气息，而且能够陈年。

常见错误：把配对搞混，例如把 Nemea 配上 Xinomavro。一个快速记忆法：Naoussa 的 N 联想到 North（北方），配北部的 Xinomavro；Nemea 在伯罗奔尼撒半岛，配 Agiorgitiko；Santorini 的 S 联想到 Sea（海），配岛上的 Assyrtiko。

希腊在 WSET Level 3 考试中会出现在哪里

WSET Level 3 考试有两个独立单元。理论单元包含 50 题选择题和 4 题简答题；品酒单元则要你运用系统品酒法盲品两款酒。每个单元都需要至少 55%，各自独立评分，如果其中一个单元没过，只需重考那个单元。希腊主要是理论主题：预期会有一两题选择题，偶尔也可能出现在某题笔试题的子题中，考一个炎热气候受海拔或海洋调节的产区。

品酒单元不会要你说出是什么酒，所以你永远不会因为认出 Assyrtiko 而得分。不过，希腊品种仍是品酒单元极佳的练习酒款：Assyrtiko 教你在酒体饱满的白葡萄酒中判断高酸度，Xinomavro 则教你把浅色泽和高单宁分开判断，这和内比奥罗设下的陷阱一模一样。用它们练习，能磨练在任何品酒笔记中都能得分的结构判断。

依单元规划复习，而不只是依章节。如果模拟考试结果显示理论单元稳过、品酒却在及格边缘，就把时间转移到品酒练习上：理论分数再高也无法弥补没通过的品酒单元，反之亦然。

附解析的练习题

以下题目以我们自己的文字撰写，用来练习考试所看重的推理方式。先读题目、大声作答，再和解析对照。

题目 1：Mantinia 位于希腊南半部，但它的白葡萄酒却酒体轻盈、酸度高。为什么？答案：Mantinia 是一片高原，海拔使气温降低，尤其是夜间。葡萄成熟缓慢并保有酸度，中等的糖分则带来较轻的酒体与酒精度。Moschofilero 本身也具有天然的高酸度与芳香花香特质，通过在不锈钢槽中低温发酵得以保留。

题目 2：为什么大多数 Nemea 酒厂认为中海拔葡萄园最适合酿红葡萄酒？答案：最低的地块温暖，Agiorgitiko 成熟很快，酿出的酒带果酱风味、柔和而酸度较低。最高的地块凉爽，葡萄能保有酸度，但成熟度可能不足以酿成饱满的红葡萄酒，所以适合做桃红葡萄酒。中海拔地块则能兼顾果实与单宁的完全成熟，以及足够的清新感。

题目 3：为什么 Xinomavro 通常需要熟成后才上市？答案：这个品种单宁高、酸度高，在年轻的酒中可能显得粗糙。在橡木桶与瓶中的时间能通过缓慢接触氧气来柔化单宁，果味也会发展成果干、辛香料与泥土气息。没有这段陈年，酒可能显得严肃生硬。

题目 4：请举出 Santorini 产量非常低的两个原因。答案：火山土壤贫瘠、保水力差，而且气候干燥多风，所以葡萄树只结出少量的小果串。这里的葡萄树也常常非常古老，而老树天生产量就较低。

小案例：Amyndeon，最凉爽的角落

Amyndeon 位于马其顿西北部，葡萄园地势高且位于内陆，冬季寒冷，春霜风险明显，是希腊最凉爽的地区之一。在较凉的年份，Xinomavro 很难完全成熟到足以酿成有结构的红葡萄酒，但它天生的高酸度反而成了优势。这就是 Amyndeon 以较轻盈的红葡萄酒、清新的桃红葡萄酒和起泡酒闻名的原因。在笔试答案中，这是酒厂依地块调整风格的完美例子：和 Naoussa 同一个品种，气候不同，酒也不同。

WSET Level 3 希腊葡萄酒术语表

  • PDO：受保护的原产地名称，最高的质量等级；大多数希腊 PDO 葡萄酒必须使用原生品种。
  • PGI：受保护的地理标志，范围较广、规范较宽松的等级，国际品种很常见。
  • Koulara：Santorini 用来抵御强风与风沙的低矮篮状整枝系统。
  • Vinsanto：Santorini 以日晒风干葡萄（主要是 Assyrtiko）酿成、经长时间橡木桶陈年的甜酒。
  • 马其顿：希腊北部较凉爽、更偏大陆型气候的地区，Naoussa 与 Amyndeon 的所在地。
  • 伯罗奔尼撒半岛：南部的大型半岛，Nemea 与 Mantinia 的所在地。
  • 雨影区：山脉背面较干燥的地区；品都斯山脉使希腊东部比西部干燥。

希腊在 WSET Level 3 考试中重要吗？

重要。50 题选择题涵盖整个课程大纲，4 题简答题则常聚焦于某个产区或工艺，因此每个主题，包括希腊，都可能出现。

WSET Level 3 需要认识哪些希腊品种？

必学的品种是 Assyrtiko（白，Santorini）、Agiorgitiko（黑，Nemea）和 Xinomavro（黑，Naoussa 与 Amyndeon）。认识 Mantinia 的桃红色果皮芳香品种 Moschofilero，以及芳香型白葡萄 Malagousia 也有帮助。每个品种都要记住它的颜色、法定产区，以及两三个风格词。

为什么 Santorini 的葡萄树要整成篮状？

在 Santorini，葡萄树被贴地整成低矮的篮状，称为 koulara，用来保护新梢与果串不受强风与风吹火山砂侵袭。篮子也能为葡萄遮阴，并帮助葡萄树利用有限的水分。这是 WSET Level 3 中整枝方式配合当地气候的经典例子。

为什么 Santorini 没有根瘤蚜？

根瘤蚜无法在 Santorini 的火山砂质土壤中存活，所以这座岛从未受到这种虫害侵袭。因此葡萄树以自根种植，许多都非常古老。古老、未嫁接、低产量的葡萄树，造就了 Santorini Assyrtiko 的浓缩度。

海拔如何影响 Nemea 的酒？

在 Nemea，Agiorgitiko 种植在很广的海拔范围内。低处温暖的地块酿出成熟、柔和、带果酱风味的红葡萄酒；中海拔葡萄园一般被认为在成熟度与酸度之间取得最佳平衡；最高的地块则酿出更轻盈、酸度更高的酒，常用来做桃红葡萄酒。这是 WSET Level 3 常见的因果题。

Santorini 的 Vinsanto 是什么？

Vinsanto 是 Santorini 的甜酒，主要以 Assyrtiko 酿成，葡萄在采收后经日晒风干以浓缩糖分。之后酒在橡木桶中长时间陈年，呈现丰厚的甜美风格，酸度高，带果干与焦糖气息。

希腊葡萄酒会出现在 WSET Level 3 品酒单元吗？

任何符合课程大纲的酒都可能被使用，但品酒单元从不要求你辨认品种或产区。评分依据是你是否准确描述外观、香气与口感，以及对质量和适饮程度的结论是否有理有据。Assyrtiko 或 Xinomavro 等希腊葡萄酒非常适合练习，因为它们能训练你正确判断高酸度与高单宁。

如果理论单元通过、品酒没过，会怎样？

WSET Level 3 的两个单元是分开的，各自的及格标准都是 55%。如果一个通过、另一个没过，通常只需重考没过的单元，另一个单元的成绩维持有效。具体安排与期限请向你的课程机构确认。这就是为什么两个单元都值得认真准备，而不要只依赖自己最强的那一个。

为什么 Amyndeon 以桃红葡萄酒与起泡酒闻名？

Amyndeon 位于希腊北部的高海拔内陆，是全国最凉爽的葡萄酒产区之一。Xinomavro 在那里不一定能成熟到足以酿成强劲的红葡萄酒，但能保有非常高的酸度。这样的酸度非常适合清新的桃红葡萄酒和起泡酒基酒，所以酒厂善用凉爽的气候，而不是与之对抗。

希腊葡萄酒可以使用国际品种吗？

可以。赤霞珠、梅洛、西拉和霞多丽在希腊都有种植，常见于 PGI 葡萄酒，并常与原生品种混酿。不过大多数 PDO 葡萄酒必须以原生品种酿造，这就是考试会把每个 PDO 联系到一个本地品种的原因，例如 Nemea 的 Agiorgitiko 或 Santorini 的 Assyrtiko。

WSET Level 3 的希腊应该花多少时间准备？

希腊是个小主题，通常几次短时间的学习就足够了。记住四组法定产区与品种的配对、海拔与海风的气候逻辑，以及 Santorini 的案例。接着练习选择题，直到分数接近满分，再把其余时间留给较大的产区和品酒单元。
