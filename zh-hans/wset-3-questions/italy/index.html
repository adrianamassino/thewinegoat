1 哪一个意大利传统用语对应 PGI（地理标志保护）？

显示答案

答案：IGT（Tipica）

解析：PDO 对应的用语是 DOP，但 DOC 与 DOCG 更常见。

2 为什么意大利北部的夏季干燥而短暂？

显示答案

答案：阿尔卑斯山形成屏障，为葡萄园挡住降雨

解析：波河等河流与加尔达湖等湖泊调节内陆地区的气温；靠近海边降雨较多，会带来真菌病害。

3 意大利最北端的葡萄酒产区是哪里？

显示答案

答案：上阿迪杰（Alto Adige）

解析：位于波札诺（Bolzano）周围，沿阿迪杰河的梯田上；巨大的日夜温差适合芳香型白葡萄酒与优雅轻盈的红葡萄酒。

4 上阿迪杰的红葡萄酒以哪个品种为主？

显示答案

答案：斯奇亚瓦（Schiava）

解析：它酿出轻盈、果味丰富、带覆盆子与李子气息的酒。主要白葡萄品种是不甜、高酸度的灰皮诺（Pinot Grigio）。

5 下列哪个意大利品种是黑葡萄？

显示答案

答案：多姿桃（Dolcetto）

解析：多姿桃：黑葡萄，皮埃蒙特。柯蒂斯（Gavi）、格雷切托（Orvieto）、维蒂奇诺（马尔凯 Marche）：白葡萄。

6 下列哪一款酒“不是”以内比奥罗酿造？

显示答案

答案：布鲁奈罗（Brunello）

解析：布鲁奈罗 = 桑娇维塞（Sangiovese，托斯卡纳）。

学习笔记：WSET Level 3 的意大利

WSET Level 3 的意大利题目涵盖一个幅员辽阔的国家，所以诀窍在于架构：由北往南学习意大利，把每个产区联系到它的主要品种与气候，再记住一小份陈年规定与酒标用语清单。由于原生品种与法定产区众多，意大利是课程大纲中分量最重的主题之一。这份学习笔记提供上述样题背后的复习架构。

意大利酒标：DOCG、DOC、IGT、Classico、Superiore、Riserva

意大利在欧盟分级之外也使用传统用语。DOCG 与 DOC 属于 PDO（原产地名称保护）葡萄酒，其中 DOCG 等级更高、规定更严格；IGT 是 PGI 等级，常用于不依法定产区规定酿造的酒，例如许多超级托斯卡纳（Super Tuscan）。另外还有几个常出现在考题中的酒标用语：

  • Classico：来自法定产区历史悠久的原始核心地带，通常位于最好的山坡地块（Chianti Classico、Soave Classico、Valpolicella Classico）。
  • Superiore：最低酒精浓度较高，有时最低陈年时间也比基本款更长。
  • Riserva：最低陈年时间比基本款更长，由各法定产区自行规定。
  • Gran Selezione：Chianti Classico 的最高等级，高于 Riserva。

WSET Level 3 的意大利北部：皮埃蒙特与威尼托

皮埃蒙特：内比奥罗、巴贝拉、多姿桃

皮埃蒙特位于阿尔卑斯山脚下，属温和的大陆性气候，秋季有雾。内比奥罗早发芽、非常晚熟，所以需要最温暖、朝南的山坡地块。它酿出的酒颜色浅，很早就出现石榴红与橙色的酒缘，酸度高、单宁高，带红樱桃、玫瑰与紫罗兰香气，陈年后发展出焦油、皮革与果干气息。巴罗洛与巴巴莱斯科是内比奥罗最顶级的 DOCG；巴巴莱斯科一般稍轻盈一些，年轻时也较易入口。巴贝拉（Barbera）颜色深、酸度高、单宁低，带红樱桃与李子，可不经橡木桶，也可使用新橡木桶（Barbera d'Asti、Barbera d'Alba）。多姿桃早熟，酿出柔顺、颜色深、果味丰富、适合早饮的红葡萄酒。柯蒂斯则酿造 Gavi，一款轻盈、高酸度的不甜白葡萄酒。

威尼托：苏瓦韦、瓦尔波利切拉、阿玛罗内

苏瓦韦（Soave）主要以卡尔卡耐卡（Garganega）酿造，是酸度中等至高、带柠檬、梨子与杏仁气息的不甜白葡萄酒；最好的酒款来自 Classico 区的火山丘陵。瓦尔波利切拉（Valpolicella）以科维纳为基础，这是一种酸度高、颜色浅、带酸樱桃风味的黑葡萄。基本款瓦尔波利切拉轻盈而果味丰富。Amarone della Valpolicella 以采收后风干的葡萄（appassimento）酿造，风干使糖分、风味与单宁浓缩；发酵至不甜后，成为酒体饱满、酒精高、带果干气息的红葡萄酒。Recioto della Valpolicella 是以同样的风干葡萄酿成的甜型版本。Valpolicella Ripasso 则是把瓦尔波利切拉放在酿完阿玛罗内后留下的果渣上再次发酵，增添酒体、酒精、单宁与果干特性。

更北边的上阿迪杰与特伦提诺，因海拔与巨大的日夜温差而出产清新的白葡萄酒与轻盈的红葡萄酒；弗留利则以高质量、常不经橡木桶的白葡萄酒闻名，例如弗留拉诺（Friulano）与灰皮诺。

意大利中部：托斯卡纳与桑娇维塞

桑娇维塞是意大利种植面积最大的黑葡萄品种，也是托斯卡纳的骨干。它晚熟，酸度高、单宁高、颜色中等，带红樱桃、李子与干燥香草风味，陈年后发展出皮革与土壤气息。托斯卡纳属温暖的地中海型气候，而最好的葡萄园所在的丘陵则因海拔而得到调节。

陈年规定与关键数字

有一小组数字反复出现。Barolo DOCG 要求至少陈年 38 个月，其中 18 个月在木桶中（Riserva 为 62 个月）。Barbaresco DOCG 要求至少 26 个月，其中 9 个月在木桶中（Riserva 为 50 个月）。Brunello di Montalcino 必须在橡木桶中陈年至少两年，且采收后五年才能上市（Riserva 为六年）。如果题目没有问确切规定，就解释其影响：在大型旧木桶或橡木桶中长期陈年，能柔化单宁并增添皮革、果干与土壤等三级香气。

常见错误：把蒙特布查诺品种（阿布鲁佐）与 Vino Nobile di Montepulciano（托斯卡纳的小镇，使用桑娇维塞）搞混。另一个经典陷阱：以为巴贝拉单宁很重。巴贝拉酸度高但单宁低；内比奥罗则两者都高。

简答题示例：Amarone della Valpolicella

考试风格题目：说明阿玛罗内如何酿造，以及这个流程如何影响它的风格。高分答案：

  1. 采收健康的科维纳果串（搭配其他当地品种），在通风良好的阁楼中摊开风干数个月。
  2. 葡萄失去水分，因此糖分、酸、风味化合物与单宁都被浓缩。
  3. 葡萄汁发酵至不甜，由于糖分高，发酵过程缓慢，带来高酒精与饱满酒体。
  4. 酒通常在橡木桶中陈年，柔化单宁并增添复杂度。
  5. 结果：一款不甜、酒体饱满的红葡萄酒，酒精高，高单宁与高酸度被浓缩的干樱桃、葡萄干与香料风味平衡，能陈年多年。

更多意大利练习题，完整解答

这些额外题目是我们用自己的文字、仿照 WSET Level 3 理论试卷风格撰写的。先试著作答再看答案，然后检查你的推理是否同时涵盖了原因与事实。

题目：大多数普洛赛克使用哪个品种与哪种方法？它们如何塑造风格？答案：普洛赛克主要以格雷拉（Glera）酿造，通常采用槽式发酵法，二次发酵在加压酒槽中进行。这种方法快速，能保留品种新鲜的一级香气，例如青苹果、梨子与哈密瓜，所以酒轻盈、果味丰富，最适合趁年轻饮用。丘陵地带的 Conegliano Valdobbiadene 是最负盛名酒款的来源。

题目：为什么 Moscato d'Asti 酒精低又甜？答案：麝香葡萄汁的发酵在酒精约 5% 时，就借由降温与过滤提早中止。未发酵的糖分留在酒中，酒保有麝香的葡萄与花香，以及发酵时保留的二氧化碳所带来的微微气泡。

题目：弗朗齐亚柯达（Franciacorta）与普洛赛克有什么不同？答案：伦巴底的弗朗齐亚柯达以传统法酿造，二次发酵在瓶中进行，并与酒泥一同陈年一段时间，主要使用霞多丽与黑皮诺。酒泥陈年增添面包、饼干气息与更细致的质地，与槽式发酵法普洛赛克的新鲜果味形成对比。

题目：圣酒（Vin Santo）如何酿造？答案：葡萄（在托斯卡纳常用特雷比亚诺与玛尔瓦西亚 Malvasia）在采收后风干以浓缩糖分，然后发酵并在小木桶中陈年数年。漫长的氧化陈年带来琥珀色泽，以及果干、坚果与焦糖风味；风格从不甜到甜型都有。

题目：为什么炎热的西西里岛上，埃特纳能酿出清新的酒？答案：葡萄园沿着火山坡地爬升到很高的地方，海拔带来较低的气温与巨大的日夜温差。葡萄保留酸度，所以 Nerello Mascalese 酿出较轻盈、高酸度的红葡萄酒，Carricante 则酿出清新、带柑橘风味的白葡萄酒。

意大利主要白葡萄品种一览

  • 柯蒂斯（Cortese）：皮埃蒙特的 Gavi；酒体轻盈、酸度高，柑橘与青绿水果。
  • 格雷拉（Glera）：普洛赛克；轻盈、清新，梨子与苹果。
  • 灰皮诺（Pinot Grigio）：上阿迪杰、弗留利、威尼托；从简单中性到最好地块的浓缩而有质地都有。
  • 维蒂奇诺（Verdicchio）：马尔凯；酸度高，柠檬与杏仁，具陈年能力。
  • 菲亚诺（Fiano）与格雷克（Greco）：坎帕尼亚；带核果风味、有质地的白葡萄酒，海拔有助保持清新感。
  • 维蒙蒂诺（Vermentino）：撒丁岛与沿海地区；清新、芳香，柑橘与香草。
  • 卡利坎特（Carricante）：埃特纳；酸度高、柑橘，风格常偏瘦削、带矿物感。

第二个简答题示例：Brunello di Montalcino 与 Chianti Classico

考试风格题目：说明为什么 Brunello di Montalcino 通常比 Chianti Classico 酒体更饱满。高分答案可以由相互联系的要点构成：

  • 蒙塔奇诺位置更偏南，一般较温暖、较干燥，所以桑娇维塞成熟得更完全。
  • 更成熟的葡萄糖分更多，所以酒的酒精更高、酒体更饱满，果味也更成熟。
  • 布鲁奈罗必须以 100% 桑娇维塞酿造，而 Chianti Classico 允许少量其他品种，所以布鲁奈罗以最浓缩的方式表现桑娇维塞。
  • 布鲁奈罗必须在橡木桶中陈年至少两年，采收后五年才能上市，所以发展出更多三级香气的复杂度与更柔顺的单宁。
  • Chianti Classico 的葡萄园常位于海拔较高、较凉爽的区域，使酒更清新、酒体更接近中等，Annata 等级尤其如此。

注意每个要点都把一个原因（例如气候、品种规定或陈年）联系到对风格的影响。这正是指令词“说明（explain）”所要求的。

WSET Level 3 中，哪些意大利产区最重要？

优先准备皮埃蒙特（内比奥罗、巴贝拉、多姿桃、Gavi）、威尼托（苏瓦韦、瓦尔波利切拉、阿玛罗内）、托斯卡纳（Chianti、Brunello、Vino Nobile、博格利）以及南部（坎帕尼亚、普利亚、西西里）。然后再加入上阿迪杰、弗留利、马尔凯、阿布鲁佐与撒丁岛，每个地区各记一个主要品种。务必把每款酒与其气候和风格联系起来。

Valpolicella Ripasso 与 Amarone 有什么不同？

阿玛罗内以发酵前风干数个月的葡萄酿造，是一款不甜、酒体饱满、酒精高、带果干风味的红葡萄酒。Ripasso 则是普通的瓦尔波利切拉放在酿完阿玛罗内后留下的果渣上再次发酵，增添酒体、酒精、单宁与些许果干特性，但程度不如阿玛罗内本身。

巴罗洛与巴巴莱斯科必须陈年多久？

Barolo DOCG 至少需陈年 38 个月，其中 18 个月在木桶中；Barolo Riserva 至少 62 个月。Barbaresco DOCG 至少需陈年 26 个月，其中 9 个月在木桶中；Barbaresco Riserva 至少 50 个月。这些数字是 WSET Level 3 选择题的常客。

在 WSET Level 3 中，什么是超级托斯卡纳？

超级托斯卡纳是不依传统法定产区规定酿造的高质量托斯卡纳红葡萄酒，过去以基本等级销售，如今通常标示为 IGT Toscana。许多酒款使用赤霞珠、梅洛或西拉，单独使用或与桑娇维塞混酿，常在新的法国橡木桶中陈年。沿海的博格利与这种风格密切相关。

意大利酒标上的 Classico 是什么意思？

Classico 表示这款酒来自该法定产区历史悠久的原始区域，通常是拥有最成熟葡萄园的丘陵核心地带。例子包括 Chianti Classico、Soave Classico 与 Valpolicella Classico。它是地理用语，本身并不保证陈年时间更长。

在 WSET Level 3 中，普洛赛克如何酿造？

普洛赛克主要以格雷拉酿造，通常采用槽式发酵法：二次发酵在加压酒槽中进行，速度快，能保留苹果、梨子与哈密瓜等新鲜一级香气。酒轻盈，最适合趁年轻饮用。丘陵地带的 Conegliano Valdobbiadene 是最负盛名酒款的来源。

弗朗齐亚柯达与普洛赛克有什么不同？

伦巴底的弗朗齐亚柯达以传统法酿造，主要使用霞多丽与黑皮诺，二次发酵在瓶中进行并与酒泥一同陈年，增添面包与饼干气息。普洛赛克主要以格雷拉用槽式发酵法酿造，保持清新、果味丰富的一级风格。

为什么 Moscato d'Asti 酒精很低？

发酵在酒精约 5% 时，就借由降温与过滤提早中止。未发酵的糖分留在酒中，所以酒是甜的，带有浓郁的麝香葡萄与花香，以及发酵时保留的二氧化碳所带来的轻微气泡。

哪个意大利黑葡萄品种颜色深但单宁低？

巴贝拉。它酿出颜色深、酸度高、单宁低的酒，带红樱桃与李子风味，可不经橡木桶，也可在新橡木桶中陈年。它与内比奥罗形成经典对比：内比奥罗颜色浅，但酸度与单宁都很高。

为什么 Brunello di Montalcino 比 Chianti Classico 更饱满？

蒙塔奇诺一般较温暖、较干燥，所以桑娇维塞成熟得更完全，带来更高的酒精与更饱满的酒体。布鲁奈罗必须是 100% 桑娇维塞，在橡木桶中陈年至少两年，并在采收后五年才上市。Chianti Classico 的葡萄园常位于较高、较凉爽之处，酒款更清新、酒体更接近中等。
