WSET Level 3 波特酒与加烈酒：练习题与解答

这些题目来自 The Wine Goat 题库中的波特酒与加烈酒单元，依照 WSET Level 3 葡萄酒认证（Award in Wines）课程大纲编写。作答、阅读解析，然后在 App 里练习完整的 52 题；你答错的题目会不断回来，直到你真正记住为止。

练习题与解答（The Wine Goat 题库）

1 Douro 的三个 Port 子产区是哪三个？

显示答案

答案： Baixo Corgo、Cima Corgo、Douro Superior

原因： Baixo Corgo 最凉爽、最多雨，酒款最轻盈；Cima Corgo 拥有最多顶级葡萄园；Douro Superior 也享有盛名。越往东越炎热干燥。

2 是什么为 Douro 挡住了带来雨水的大西洋风？

显示答案

答案： Serra do Marão 山脉

原因： 这里是温暖的大陆性气候；葡萄园从 Porto 与 Gaia 上游 70 公里处开始。

3 Port 的发酵在酒精浓度达到多少时被中止？

显示答案

答案： 5–9% abv，大约 24–36 小时后

原因： 时间太短，一般的萃取方式强度不够：因此会使用脚踩、自动酿酒槽（autovinifier）、活塞系统与机械 lagar。

显示答案

答案： 用来以脚踩踏葡萄的浅型花岗岩槽

原因： 它是其他方法的比较基准；非常耗费人力，但部分高级酒款至今仍在使用。

5 Douro 种植最广的葡萄品种是哪一个？

显示答案

答案： Touriga Franca

原因： 种植最多的是 Touriga Franca；最受推崇的是 Touriga Nacional（产量低）。

6 加烈后的 Port 酒精浓度是多少？

显示答案

答案： 19-22% abv

原因： 加烈会杀死酵母；加烈的时机取决于葡萄汁的糖度与想要的甜度。

学习笔记：WSET Level 3 波特酒与加烈酒

WSET Level 3 的 Port 题目有清楚的模式：Douro 的气候与葡萄园、加烈如何运作，以及最重要的，各种 Port 风格之间的差异。其他加烈酒的题目，例如天然甜葡萄酒（Vins Doux Naturels）、Madeira 与 Rutherglen Muscat，考的是加烈的时机与陈年方式如何塑造风格。Sherry 有自己的专页；这份笔记涵盖 Port 以及上面练习题背后的其他加烈酒。

什么是加烈酒

加烈酒是加入了葡萄烈酒的葡萄酒。如果在发酵过程中加入烈酒，它会杀死酵母并留下天然的葡萄糖分，所以酒是甜的：Port、天然甜葡萄酒与 Rutherglen Muscat 就是这样酿成的。如果在发酵结束后才加入烈酒，酒就是不甜的，除非之后再加甜，大多数 Sherry 就属于这种情况。光是这一个概念，就能解释加烈酒考题中很大一部分的答案。

Douro：Port 的气候、土壤与葡萄园

Port 来自葡萄牙北部的 Douro 河谷。Serra do Marão 山脉为河谷挡住大西洋的雨水，所以气候是温暖的大陆性气候，越往东越炎热干燥。夏季非常炎热、雨量少，葡萄树可能遭受水分逆境。

  • 片岩土壤占主导：这种岩石呈垂直方向裂开，所以葡萄树的根能在干燥的夏季深入地下寻找水分。
  • 河谷两侧非常陡峭，因此葡萄园都种在梯田上。
  • Socalcos 是以干砌石墙支撑的传统狭窄梯田，非常耗费人力。
  • Patamares 是用推土机开出的较宽梯田，没有石墙，可以进行部分机械化作业。
  • Vinha ao alto 是沿着坡面垂直种植，在坡度允许的地方使用。

Douro 分为三个子产区。Baixo Corgo 位于最西边，最凉爽也最多雨，出产较轻盈的酒，用于基本款的 Ruby 与 Tawny。以 Pinhão 为中心的 Cima Corgo 拥有大部分顶级葡萄园（quinta）。位于东边的 Douro Superior 最炎热干燥，对优质葡萄酒的重要性日益提升。

Port 的葡萄品种

Port 通常是混调酒。Touriga Nacional 是最受推崇的品种，颜色深、单宁高、酒体饱满，带浓郁的黑色水果与花香，但产量低。Touriga Franca 是种植最广的品种，带来香气与细致度。Tinta Roriz（Tempranillo）、Tinta Barroca 与 Tinto Cão 则构成主要品种名单的其余部分。在老葡萄园中，多品种混植的田间混酿（field blend）仍很常见。

Port 如何酿造：萃取与加烈

  1. 葡萄经破碎后开始发酵，但发酵只会持续约 24 到 36 小时。
  2. 因为发酵时间很短，萃取必须快速而强烈：会使用在 lagar 中脚踩、机械 lagar、自动酿酒槽，以及淋汁或活塞系统。
  3. 当葡萄汁达到约 5 到 9% abv 时，把酒液排出，并与约 77% abv 的葡萄烈酒（aguardente）混合。
  4. 烈酒杀死酵母，留下残糖；最终的 Port 约为 19 到 22% abv。
  5. 接着进行陈年，可以在限制氧气接触的大型容器中（ruby 风格），或在允许氧化的较小木桶中（tawny 风格）。

陈年的地点很重要。传统上，Port 在靠近海岸的 Vila Nova de Gaia 酒窖中陈年，那里较凉爽潮湿。在较炎热的 Douro 陈年的酒，可能会发展出一种常被称为“Douro bake”的煮熟、烘烤风味。

WSET Level 3 的 Port 风格：ruby 与 tawny 两大家族

每一种 Port 风格都属于两大家族之一。Ruby 风格在大型容器中陈年、接触的氧气很少，以保留深沉的颜色与新鲜的红色与黑色水果；最好的酒款会在瓶中继续陈年。Tawny 风格则在小型木桶（约 550 升的 pipe）中陈年多年，氧化让颜色转为黄褐色，风味转向坚果、焦糖、咖啡与果干。

其他加烈酒：VDN、Madeira 与 Rutherglen Muscat

天然甜葡萄酒 Vins Doux Naturels（法国）

天然甜葡萄酒是在发酵过程中加烈（mutage）的甜酒。Muscat VDN，例如南罗讷河的 Muscat de Beaumes-de-Venise 与 Roussillon 的 Muscat de Rivesaltes，通常以 Muscat Blanc à Petits Grains 酿造，并在年轻时隔绝氧气装瓶，以保留明显的葡萄、花香与橙花香气。Roussillon 的 Grenache VDN，例如 Banyuls 与 Maury，可以酿成还原风格，果味丰富、颜色深沉；也可以酿成氧化风格，在接触氧气的情况下陈年，带坚果与 rancio 风味。

Madeira（葡萄牙）

Madeira 的独特之处在于它会被刻意加热。在 estufagem 法中，酒在槽中加热至少三个月，速度较快，用于平价酒款。在 canteiro 法中，酒在温暖阁楼的木桶中缓慢陈年多年，用于最好的酒款。热与氧化带来焦糖、太妃糖、坚果与果干风味，以及非常高的酸度，并让 Madeira 极为长寿，开瓶后也很稳定。甜度取决于加烈的时机：甜型较早加烈，不甜型则较晚。高贵品种由最不甜到最甜依序为：Sercial、Verdelho、Boal（Bual）与 Malmsey（Malvasia）。Tinta Negra 是种植最多的品种，大多数 Madeira 都用它酿造。

Rutherglen Muscat（澳大利亚）

Victoria 的 Rutherglen 属于炎热的大陆性气候。一种深色果皮的 Muscat Blanc à Petits Grains 被留在树上晚收、部分干缩，使糖分浓缩。发酵很早就以烈酒中止，保留非常高的糖分。酒在老木桶中陈年，常放在炎热的棚屋里，并以分层系统跨年份混调。结果是非常甜、非常浓缩的酒，带果干、太妃糖、咖啡与香料风味。四个质量等级代表酒龄与丰厚度逐级提升：Rutherglen、Classic、Grand 与 Rare。

简答题示例：Tawny 与 Vintage Port 的比较

考试风格的题目：解释为什么 20 Year Old Tawny 与年轻的 Vintage Port 喝起来如此不同。好的答案：两者在加烈之前的酿造方式相同，都是短时间发酵、强烈萃取，再以 aguardente 加烈并留下残糖。Tawny 在小型 pipe 中陈年多年，氧气缓慢进入，颜色褪成黄褐色，一级果香转为果干，并发展出坚果、焦糖与咖啡的风味；它经过过滤，可以直接饮用。Vintage Port 来自单一声明年份，只在大型容器中陈年 2 到 3 年就不过滤装瓶，所以保有深沉的颜色、浓郁的黑色水果与扎实的单宁，需要数十年的瓶中陈年才会变得柔顺，并会产生需要醒酒换瓶的沉淀。

简答题示例：ruby Port 如何保留果味

题目：解释 Reserve ruby Port 的酿造方式，如何让酒拥有浓郁的果味、深沉的颜色与甜度。（参考答案）

Port 的发酵时间很短，因为只进行 24 到 36 小时就被中止，所以颜色与单宁必须非常快速地萃取出来。生产者使用强力的方法，例如在 lagar 中脚踩、带活塞的机械 lagar，或自动酿酒槽与淋汁。这种快速而强烈的萃取，带来深沉的颜色，以及平衡甜度与酒精所需的单宁。

当发酵中的葡萄汁达到约 5 到 9% 酒精时，就以约 77% abv 的葡萄烈酒加烈。酵母被杀死，因此保留了大量天然葡萄糖分，最终的酒约有 19 到 22% 酒精。接着，ruby Port 在大型老容器中短暂陈年，例如大型橡木槽或不锈钢槽，这些容器限制了与氧气的接触，保留新鲜的黑色水果。装瓶前会进行澄清与过滤，让它可以直接饮用且不会产生沉淀。Reserve ruby 以质量较高的酒酿造，比基本款 ruby 更浓郁、更复杂。

这里大部分的分数来自两个联系：短时间发酵导致强力萃取，以及氧气接触少的大型老容器保留果味。把这两点都写成因果关系。

波特酒与加烈酒的常见错误

  • 说 Port 是在发酵结束后才加烈：加烈会中断发酵，这就是酒之所以甜的原因。
  • 把 tawny Port 描述成以白葡萄酿造：tawny 来自黑葡萄，它的颜色来自在小型木桶中长时间的氧化陈年。
  • 把 LBV 和 Vintage Port 搞混：LBV 来自单一年份，但在木桶中陈年四到六年；Vintage 只在木桶中待约两年，主要在瓶中陈年。
  • 忘了天然甜葡萄酒和 Port 一样，是在发酵过程中加入中性葡萄烈酒，但烈酒浓度更高、用量更少。
  • 忽略 Madeira 的加热过程（estufagem 或 canteiro），而这正是它开瓶后依然稳定的原因。

品酒单元中的加烈酒

在 Level 3，理论与品酒是两个独立的单元，各自最低需要 55%，没过的单元单独重考。加烈酒可能出现在品酒考试中，所以要练习完整描述一款加烈酒。注意高酒精，你会感觉到温热感；并仔细判断甜度，因为高酸度或高单宁可能让甜酒显得没那么甜。Ruby Port 是深宝石红或紫色，带黑色水果与扎实的单宁；tawny 则是黄褐色或石榴红色，带果干、坚果、焦糖，单宁较柔和。在结论中，判断这款酒是现在就适饮，还是具备继续发展的结构。

在 WSET Level 3 中，ruby Port 与 tawny Port 有什么不同？

Ruby Port 在大型容器中陈年、接触的氧气很少，所以保有深沉的颜色与新鲜的红色与黑色水果。Tawny Port 则在小型木桶中陈年多年，缓慢的氧化让颜色转为黄褐色，并发展出坚果、焦糖与果干风味。Vintage、LBV 与 Reserve 属于 ruby 家族；标示酒龄的 Tawny 与 Colheita 属于 tawny 家族。

LBV 和 Vintage Port 有什么不同？

两者都来自单一年份。Vintage Port 只在声明年份酿造，2 到 3 年后不经过滤装瓶，需要长时间瓶中陈年与醒酒换瓶。LBV 在采收后 4 到 6 年装瓶，通常经过过滤，所以更柔顺，上市即可饮用，不过未过滤的 LBV 可能会产生沉淀。

为什么 Madeira 要加热？

加热重现了在热带高温中长途航海的效果，历史上这种航程让酒变得更好。在 estufagem 中，酒在槽中加热至少三个月；在 canteiro 中，酒在温暖的阁楼里缓慢陈年。热与氧化创造出焦糖、坚果与果干风味，并让 Madeira 极为稳定且长寿。

天然甜葡萄酒中的 mutage 是什么？

Mutage 是在发酵中的葡萄汁里加入葡萄烈酒以中止发酵，保留天然葡萄糖分。它用于法国的天然甜葡萄酒，例如 Muscat de Beaumes-de-Venise、Banyuls 与 Maury。Muscat VDN 通常在年轻时装瓶，以保留葡萄与花香；而部分 Grenache VDN 则经氧化陈年，带出坚果风味。

Port 使用哪些葡萄品种？

主要的 Port 葡萄品种是 Touriga Nacional，最受推崇，颜色深、果味浓郁，但产量低；Touriga Franca，种植最广；以及 Tinta Roriz（Tempranillo）、Tinta Barroca 与 Tinto Cão。大多数 Port 都是混调酒，老葡萄园中常有多品种的田间混酿。

为什么 Port 的发酵时间这么短？

当葡萄汁达到约 5 到 9% 酒精时就会加烈，通常只经过 24 到 36 小时，以保留天然葡萄糖分。在这么短的时间内，酿酒师必须萃取出足够的颜色与单宁来平衡甜度与高酒精，这就是为什么要使用脚踩、机械 lagar 与自动酿酒槽等强力方法。

开瓶后的 Port 可以保存多久？

取决于风格。Ruby 与 tawny Port 经过过滤，相当稳定，开瓶后可保存数周；而 tawny 在木桶中已经接触过氧气，通常保存得最久。Vintage Port 与未过滤的 LBV 最好在一两天内喝完。Madeira 是最耐放的，因为它在酿造过程中已经氧化并加热过。

Port 会出现在 WSET Level 3 的品酒单元吗？

有可能。理论与品酒是两个独立的单元，各自需要至少 55%。如果你品酒到一款加烈酒，要描述高酒精、甜度等级、单宁，以及果味或三级风味特征，然后判断质量与适饮程度。你不需要说出它的风格，但你的描述应该精确到足以支持合乎逻辑的结论。

Single Quinta Vintage Port 和经典的 Vintage Port 有什么不同？

经典的 Vintage Port 通常混调了生产者多座葡萄园中最好的酒，只在最好的年份声明。Single Quinta Vintage Port 来自单一酒庄，常在质量好但未声明为经典年份的年份酿造。两者都在年轻时不经过滤装瓶，都需要长时间瓶中陈年。

tawny Port 适合搭配什么食物？

Tawny Port 带果干、坚果与焦糖风味，很适合搭配以坚果、焦糖或果干为主的甜点，例如杏仁塔或焦糖布丁，也适合搭配陈年的硬质奶酪。它通常略微冰凉后侍酒。酒的甜度至少要和甜点一样高，否则酒会尝起来单薄而尖锐。
