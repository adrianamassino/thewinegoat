样题与解答

1 对葡萄牙气候影响最大的单一因素是什么？

显示答案

答案：大西洋

解析：许多地区属于海洋性气候，但不少内陆葡萄园炎热、干燥且属大陆型气候；部分地区的海拔能缓和炎热。

2 至今仍会出现在酒标上的葡萄牙传统 PGI 用语是什么？

显示答案

答案：Vinho Regional

解析：PDO = DOP（传统上称 DOC）；PGI = IGP。没有地理标志的酒称为“Vinho”，其中包括销售成功的简单微甜桃红葡萄酒。

3 Vinho Verde 最显著的气候特征是什么？

显示答案

答案：降雨丰沛

解析：若没有树冠管理，雨水会导致枝叶过度生长与病害；传统的棚架已逐渐被短梢修剪的垂直新梢定位（VSP）取代，以利通风与机械化。

4 经典的 Vinho Verde 白葡萄酒是什么样子？

显示答案

答案：浅柠檬色、高酸度、低酒精，常带轻微气泡感

解析：酒精较低的酒款通常微甜。品种为 Loureiro 与 Arinto。若标示品种或子产区，酒精浓度最高可达 14%。

5 Vinho Verde Alvarinho 来自哪里？风格如何？

显示答案

答案：来自 Monção e Melgaço；11.5–14%，带更成熟的热带水果香气

解析：100% Alvarinho（在西班牙称为 Albariño）。Vinho Verde 的红葡萄酒颜色深、单宁高，桃红葡萄酒则清新果香。

6 哪些当地品种用于酿造 Vinho Verde 白葡萄酒？

显示答案

答案：Loureiro 与 Arinto

解析：Vinho Verde：Loureiro、Arinto；Monção e Melgaço 则以 Alvarinho 为主。

学习笔记：WSET Level 3 的葡萄牙

WSET Level 3 的葡萄牙题目考三件事：大西洋与山脉如何塑造各产区的气候、哪些原生品种种在哪里，以及如何解读葡萄牙酒标。以下笔记从潮湿的西北部到炎热的南部逐区整理，采用简答题看重的“原因、结果、风格”推理方式。波特酒有独立的主题，所以这里的重点放在一般（未加烈）葡萄酒，只简短提到 Moscatel de Setúbal。

为什么大西洋是理解葡萄牙的关键

大西洋是影响葡萄牙气候最重要的单一因素，因为盛行西风把凉爽空气与雨水带上海岸。越往内陆，山脉阻挡了海洋影响，降雨量急遽减少，夏季也变得更炎热干燥。这就是为什么靠近西北海岸的绿酒产区（Vinho Verde）是欧洲最潮湿的葡萄酒产区之一，而位于马朗山脉（Serra do Marão）后方、离海不远的杜罗河谷（Douro）却炎热干燥。当题目要你解释两个葡萄牙产区的差异时，先从离海远近与山脉屏障写起，再补充海拔与土壤。

第二个重要概念是品种组合。葡萄牙拥有大量原生品种，考试要求你把其中几个与产区联系：西北部的 Loureiro、Arinto 与 Alvarinho；Douro 与 Dão 的 Touriga Nacional、Touriga Franca 与 Tinta Roriz；Bairrada 的 Baga；Alentejo 的 Alicante Bouschet、Trincadeira 与 Antão Vaz；南部的 Castelão。

WSET Level 3 葡萄牙酒标用语

葡萄牙酒标采用欧盟分类，但使用传统名称。DOP 是受保护的原产地名称，至今仍普遍写作 DOC。IGP 是受保护的地理标志，通常标示为 Vinho Regional。没有地理标志的酒则直接标为 Vinho。有两个陈年用语经常出现在 WSET Level 3 葡萄牙题目中。

用语意义考试重点
DOP / DOCPDO：划定的产区、许可品种、产量与生产规定Douro、Dão、Bairrada、Vinho Verde、Alentejo
IGP / Vinho RegionalPGI：范围较大，品种选择更自由Vinho Regional Alentejano、Lisboa 与 Tejo 销量很大
Vinho没有地理标志的葡萄酒包括商业上很成功的微甜桃红葡萄酒
Reserva单一年份，酒精浓度至少比该产区法定最低值高 0.5% abv本身并不保证经过橡木桶陈年
Garrafeira单一年份；红葡萄酒至少陈年 30 个月，其中至少 12 个月在瓶中；白葡萄酒至少 12 个月，其中 6 个月在瓶中酒庄精选的最佳酒款，上市前经过陈年

常见错误：写成 Reserva 代表酒在全新橡木桶中陈年。在葡萄牙，法定定义与年份和酒精有关；是否使用橡木桶由酒庄决定。Garrafeira 才是规定了最低陈年期（部分须在瓶中）的用语。

WSET Level 3 的 Vinho Verde：气候、栽培与风格

Vinho Verde DOC 位于最西北端的米纽（Minho）。丰沛的雨量与肥沃的花岗岩土壤，让葡萄树生长非常旺盛，真菌病害的风险也很高。传统上葡萄树被高高架在棚架上或攀附在树上，好让地面种植其他作物。如今大多数葡萄园采用单臂式整枝、短梢修剪与垂直新梢定位，因为开阔通风的树冠能降低病害压力，也方便机械化。葡萄提早采收，因此酒能保持高酸度与中低酒精。

必须知道的 Vinho Verde 风格

  • 经典白葡萄酒混调：浅柠檬色、高酸度、轻盈酒体、低酒精，带柑橘与青色水果香气，常有轻微气泡感与一丝甜味；在不锈钢槽中低温发酵，年轻时装瓶。
  • Loureiro：花香与柑橘香气；Arinto：酸度非常高、带柠檬果香，能为混调增添清新感。
  • Monção e Melgaço 的 Alvarinho：这个子产区受丘陵屏障，更温暖干燥，葡萄能更充分成熟，酒体更饱满、酒精更高，带更成熟的核果与热带水果香气。
  • 顶级白葡萄酒：部分酒庄会通过酒泥接触或部分使用橡木桶来增加质地。
  • 红葡萄酒与桃红葡萄酒：红葡萄酒颜色深、酸度高、单宁明显；桃红葡萄酒清新果香。

Douro DOC：杜罗河谷的未加烈葡萄酒

Douro 以波特酒闻名，但 WSET Level 3 也要求你认识不甜的 Douro DOC 红葡萄酒与白葡萄酒，它们的质量与声誉都快速提升。河谷受马朗山脉阻挡大西洋雨水，因此属于炎热干燥的大陆型气候。土壤主要是片岩，会垂直裂开，让根系深入地下寻找水源，这在承受干旱压力的产区至关重要。坡度非常陡峭：古老的石墙梯田、以推土机开辟、可让小型曳引机通行的宽梯田（patamares），以及沿坡垂直种植（vinha ao alto）都有使用。

这个产区有三个子产区，越往东越炎热、干燥、人烟稀少：下科尔哥（Baixo Corgo，最潮湿凉爽）、上科尔哥（Cima Corgo，产区核心，许多顶级酒庄 quinta 所在地）与上杜罗（Douro Superior，最炎热干燥）。主要黑葡萄品种为 Touriga Nacional（颜色深、单宁高，带花香与黑色水果香气）、Touriga Franca、Tinta Roriz（即 Tempranillo）、Tinta Barroca 与 Tinto Cão。典型的顶级 Douro 红葡萄酒颜色深、酒体饱满、单宁高、带成熟黑色水果风味，常在橡木桶中陈年，具陈年潜力。白葡萄酒主要来自海拔较高、较凉爽、能保留酸度的地块。

WSET Level 3 的 Dão 与 Bairrada

Dão

Dão 位于群山环绕的花岗岩高原上。山脉替它挡住西边最潮湿的大西洋天气，也挡住东边最严酷的大陆型气候，海拔则带来凉爽的夜晚。因此 Dão 红葡萄酒能保持高酸度与优雅的结构。主要黑葡萄品种为 Touriga Nacional、Tinta Roriz、Alfrocheiro 与 Jaen（与 Mencía 为同一品种）。红葡萄酒通常为中等至饱满酒体，单宁中等至高，带红色与黑色水果风味，陈年潜力佳。代表性白葡萄是 Encruzado，可以在橡木桶中发酵并进行酒泥陈年，酿出酒体饱满、复杂且耐陈年的白葡萄酒。

Bairrada

Bairrada 靠近海岸，属于海洋性气候，降雨量可观，许多葡萄园位于黏土上。代表品种是 Baga，一种皮厚、晚熟、酸度与单宁都高的品种。由于成熟较晚，潮湿的秋季会带来腐烂风险，以及未成熟、粗糙的单宁。传统 Bairrada 红葡萄酒单宁非常高，需要在瓶中陈放多年；许多现代酒庄完全去梗、萃取更温和，并选择最好的地块，酿出更柔和、果香更丰富的酒。Bairrada 也是传统法起泡酒的重要产地，Bical 则是当地的白葡萄品种。

葡萄牙南部：Lisboa、Tejo、Alentejo 与 Setúbal

南部更温暖、地势更开阔，许多酒以 Vinho Regional 名义销售，可以混调当地与国际品种。Lisboa 沿着海岸延伸，大量生产果香丰富、物超所值的酒。Tejo 沿着特茹河（Tagus）分布：靠近河岸的肥沃平原产量高，离河较远的贫瘠土壤则酿出更浓缩的酒。Alentejo 是一个广大、炎热、干燥的产区，常需要灌溉；大型酒庄与合作社以 Aragonez（即 Tempranillo）、Trincadeira 以及颜色极深的染色葡萄 Alicante Bouschet 酿造饱满红葡萄酒，常与 Syrah 或 Cabernet Sauvignon 混调；白葡萄酒则用 Antão Vaz、Roupeiro 与能增添酸度的 Arinto。在塞图巴尔半岛（Península de Setúbal），Castelão 在沙质土壤上生长良好，Moscatel de Setúbal 则是一种甜型加烈酒。

如何回答 WSET Level 3 葡萄牙简答题

葡萄牙的简答题是逐点给分，所以结构比文采更重要。像是“解释为什么 Douro 红葡萄酒酒体饱满、单宁高”这样的题目，请依照以下顺序：

  1. 写出气候及其成因：夏季炎热干燥、属大陆型，因为马朗山脉阻挡了大西洋的雨水。
  2. 补充土壤与地块：片岩让根系深入寻找水源；陡坡面向阳光。
  3. 联系到品种：Touriga Nacional 与 Touriga Franca 皮厚，带来深色泽与高单宁。
  4. 提到酿造：顶级酒款会加强萃取并在橡木桶中陈年。
  5. 最后写风格：深红宝石色、酒体饱满、单宁高、成熟黑色水果、具陈年潜力。

考试技巧：回答葡萄牙题目时，一定要把品种与产区一起写出（Bairrada 的 Baga、Dão 的 Encruzado、Monção e Melgaço 的 Alvarinho）。许多选择题的干扰选项，就是把真实存在的品种配上错误的产区。

  • 第 2 天：品种配对：写下每个产区及其两到三个主要品种，再对照检查。
  • 第 3 天：酒标用语：凭记忆写出 DOP、IGP、Vinho Regional、Reserva 与 Garrafeira。
  • 第 4 天：写一篇关于 Vinho Verde 葡萄栽培的五点式简答，再写一篇关于 Douro 红葡萄酒的。

示例解析：葡萄牙简答题

题目 1：解释为什么经典的 Vinho Verde 白葡萄酒酒体轻盈、酸度高。参考答案：这个产区位于西北部、靠近大西洋，因此凉爽且非常潮湿。葡萄在完全成熟前提早采收，使酸度保持在高档、糖分偏低，酿出中低酒精、酒体轻盈的酒。Loureiro 与 Arinto 等品种带来柑橘、花香与清新的酸度，而在不锈钢槽中低温发酵并及早装瓶，则保留了初级果香，有时还带轻微气泡感。

题目 2：解释 Alentejo 的酒庄如何在炎热干燥的气候中酿出饱满的红葡萄酒。参考答案：炎热晴朗的夏季让黑葡萄充分成熟，糖分高，因此酒精高、带成熟黑色水果风味。干旱时常需要灌溉，让葡萄树维持正常运作。酒庄选择适应炎热的品种，例如 Trincadeira、Aragonez 与 Alicante Bouschet，后者的红色果肉能带来非常深的颜色。以 Vinho Regional Alentejano 名义销售的混调可以加入 Syrah 或 Cabernet Sauvignon，顶级酒款则在橡木桶中陈年以增加结构。

葡萄牙在 WSET Level 3 考试中的定位

Level 3 分成两个独立单元，每个都至少需要 55%：理论单元有 50 题选择题与 4 题简答题，品酒单元则盲品评估两款酒。两者分开评分，所以如果某个单元没过，只需重考该单元。葡萄牙在理论部分常以产区与品种配对、酒标用语与气候说明的形式出现。品酒练习时，一款 Vinho Verde 和一款 Douro 红葡萄酒是很好的对照组：一款展现高酸度与轻盈酒体，另一款则展现深色泽、高单宁与饱满酒体。

葡萄牙答案中的常见错误

  • 把 Douro 描述成海洋性气候：马朗山脉阻挡了大西洋雨水，所以那里炎热干燥。
  • 把 Baga 配到 Douro：Baga 属于 Bairrada。
  • 以为 Alvarinho 喝起来像经典的 Vinho Verde 混调：在 Monção e Melgaço，它更饱满、更成熟。
  • 把 Alicante Bouschet 说成葡萄牙当地的杂交品种：它是一种染色葡萄，因颜色而备受重视。

专注在与特定产区联系的品种：Vinho Verde 的 Loureiro、Arinto 与 Alvarinho；Douro 的 Touriga Nacional、Touriga Franca 与 Tinta Roriz；Dão 的 Touriga Nacional、Alfrocheiro、Jaen 与白葡萄 Encruzado；Bairrada 的 Baga；Alentejo 的 Alicante Bouschet、Trincadeira、Aragonez 与 Antão Vaz；Setúbal 的 Castelão。知道每个品种的主要结构特征，对简答题很有帮助。

葡萄牙的 Reserva 和 Garrafeira 有什么不同？

两者都必须来自单一年份。Reserva 表示酒精浓度至少比该产区法定最低值高 0.5% abv；它并没有特别规定橡木桶。Garrafeira 则多了最低陈年期：红葡萄酒上市前至少陈年 30 个月，其中至少 12 个月在瓶中；白葡萄酒至少 12 个月，其中 6 个月在瓶中。

Dão 位于内陆，为什么红葡萄酒酸度高？

Dão 位于群山环绕的花岗岩高原上。海拔带来凉爽的夜晚，减缓成熟过程中酸度的流失，而山脉则让葡萄园免受大西洋豪雨与大陆型极端气候的影响。结果是酸度高、单宁中等至高、结构优雅且耐陈年的红葡萄酒，这是 WSET Level 3 常见的说明题。

在 WSET Level 3 中，Douro DOC 和波特酒是一样的吗？

不一样。波特酒是拥有独立法定产区的加烈酒，而 Douro DOC 涵盖同一河谷的未加烈红葡萄酒与白葡萄酒。它们共享气候、片岩土壤与 Touriga Nacional、Touriga Franca 等品种，但 Douro DOC 红葡萄酒不加烈酒、发酵至不甜，成为酒体饱满、单宁高的不甜酒。

为什么 Baga 在 Bairrada 很难种植？

Baga 皮厚、晚熟，而 Bairrada 属于多雨的海洋性气候。如果秋季潮湿，酒农就要冒着腐烂的风险，或在单宁完全成熟前采收，酿出粗糙、涩口的酒。现代酒庄通过谨慎选择地块、完全去梗与更温和的萃取来应对，酿出更柔和、又保有 Baga 高酸度的红葡萄酒。

什么是 Alicante Bouschet 这类染色葡萄？

染色葡萄是一种不只果皮、连果肉都是红色的黑葡萄。它的果汁本身就有颜色，因此即使浸皮时间很短，也能带来非常深的颜色。在 Alentejo，Alicante Bouschet 因其颜色、成熟黑色水果风味与结构而受到重视，常与 Trincadeira、Aragonez 或国际品种混调。在考试答案中，把它写成深色泽的来源。

为什么最好的 Douro 白葡萄酒种在高海拔地区？

Douro 炎热干燥，种在低处、日照充足地块的白葡萄成熟很快，酸度也随之流失。海拔较高的葡萄园气温较低，尤其是夜间，因此成熟较慢，葡萄能保有更清新的酸度与更芬芳的果香。这就是为什么许多酒庄从产区的高海拔地带取得白葡萄，那里的酒更均衡、更清爽。

如何为 WSET Level 3 理论考卷练习葡萄牙？

先从一张空白地图与五个主要产区开始，再为每个产区加上一个气候关键词与两个品种。接着限时写关于 Vinho Verde 葡萄栽培与 Douro 红葡萄酒的五点式简答。最后做综合选择题，仔细查看那些把真实品种配上错误产区的干扰选项；在 App 中反复复习这些错误直到它们消失，是进步最快的方法。
