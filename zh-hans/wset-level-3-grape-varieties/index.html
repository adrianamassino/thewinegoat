WSET Level 3 必知的葡萄品种

重点摘要

WSET Level 3 必知的葡萄品种：每个品种种在哪里、能酿出哪些风格，以及如何在考试答案中把品种、气候与酿造方式联系起来，拿到更多分数。

更新于 2026-11-15 · The Wine Goat

到了 Level 3，只知道品种的名字是不够的：你必须解释它为什么在某个地方会呈现这样的味道。每个品种对气候、土壤与酿造选择的反应各不相同，而考试奖励的正是这种推理。

从下面的国际品种开始，再随着你读到每个产区，加入当地的品种。

用 Level 3 的方式学品种

  • 把每个品种当成一份画像来学：颜色、酸度、单宁、典型香气、对橡木桶的反应。
  • 联系到气候：同一个品种在凉爽与温暖的产区会酿出两种不同的酒，两种都要知道。
  • 加上酿造：例如霞多丽有没有经过乳酸转换、酒泥接触与新橡木桶。
  • 用混合题目测验自己：品种 → 产区、产区 → 品种、风格 → 品种。

不可忘记的地区性品种

考官很爱考地区性品种：阿尔巴利诺 Albariño（Rías Baixas）、弗德乔 Verdejo（Rueda）、Assyrtiko（Santorini）、绿维特利纳 Grüner Veltliner（奥地利）、福明 Furmint（Tokaj）、特浓情 Torrontés（萨尔塔）、皮诺塔吉 Pinotage（南非）、佳美娜 Carmenère（智利）、仙粉黛 Zinfandel（加州）、国产多瑞加 Touriga Nacional（杜罗河谷）、艾格尼科 Aglianico、菲亚诺 Fiano 与黑达沃拉 Nero d'Avola（意大利南部）。学习时要连同它们的产区与主要风格一起记。

为什么品种是每一题 Level 3 答案的起点

在 Level 3，葡萄品种不是一个要背的名字，而是一组能解释一款酒的特性。每个品种都有自己的天然酸度、果皮厚度、单宁、香气强度与成熟时间。这些特性决定了这个品种能在哪里顺利成熟、葡萄种植者必须处理哪些问题，以及哪些酿造选择合理。当考题问一款酒为什么呈现这样的味道时，品种几乎总是答案的一部分。

这一点在认证的两个单元中都很重要。在包含 50 题选择题与 4 题简答题的理论单元中，品种知识会出现在辨识题与产区风格的解释中。在独立评分、同样需要至少 55% 的品酒单元中，你不必说出品种，但认识典型画像能帮你有信心地判断结构，并得出合理的结论。如果一个单元没过，你只需重考那个单元，所以扎实的品种知识能在两方面都帮上你。

如何解读品种画像

在背个别品种之前，先学会描述任何品种的六个问题。只要能为某个品种回答这六个问题，你就能预测它在葡萄园与杯中的大部分表现。

  1. 它何时发芽与成熟？早发芽的品种有春霜风险；晚熟的品种需要漫长温暖的生长季才能完全成熟。
  2. 它的果皮有多厚？厚皮带来更多颜色与单宁，也能抵抗腐烂；薄皮酿出的酒颜色较浅，在潮湿天气中也较脆弱。
  3. 它的天然酸度如何？高酸品种在温暖气候中仍能保持清新，也能支撑甜酒与起泡酒的风格。
  4. 它的香气有多浓郁？芳香型品种通常不使用新橡木桶，以保护它的特性；中性品种则对橡木桶、酒泥与乳酸转换反应良好。
  5. 它能带来多少单宁？这决定了黑葡萄酒的结构，也常决定它们的陈年潜力。
  6. 它有哪些弱点？病害、成熟不均或着果不良，解释了许多产区的选择。

有了这六个答案，每一项产区知识都变得合乎逻辑。皮薄、早熟的黑葡萄属于凉爽产区；晚熟、皮厚的品种需要温暖；高酸的白葡萄则能酿出从极干到浓郁甜美的任何酒款。

主要白葡萄品种详解

霞多丽（Chardonnay）

霞多丽很早发芽，因此在 Chablis 等凉爽产区，春霜是真正的风险。它的香气相对中性，所以能清楚反映气候与酿造方式。在凉爽气候中，它呈现青苹果、柑橘与高酸度；在温和气候中，呈现核果与哈密瓜；在温暖气候中，则是热带水果且酸度较低。酿酒师可以通过乳酸转换带来奶油般的绵密气息、通过酒泥接触增加质地，并通过橡木桶增添香草与烤面包风味。它也是传统法起泡酒的重要品种，包括 Blanc de Blancs 香槟。

长相思（Sauvignon Blanc）

长相思香气浓郁、酸度高，带青草、青椒与芦笋等绿色气息，以及醋栗、柑橘，在较温暖的地块还有百香果。它的香气最好通过不锈钢槽低温发酵与提早装瓶来保留，这是马尔堡以及卢瓦尔河中央葡萄园区（例如 Sancerre 与 Pouilly-Fumé）的典型做法，后者的风格通常较内敛。在波尔多，它常与赛美蓉混酿，有时在橡木桶中发酵与陈年，而同样的混酿也是贵腐甜酒的基础。

雷司令（Riesling）

雷司令香气非常浓郁、酸度非常高，特别擅长表现地块特色。它是晚熟品种，木质坚硬，能抵抗冬季严寒，适合秋季漫长的凉爽产区。它呈现绿色水果、柑橘、核果与花香，瓶中陈年后会发展出蜂蜜、烤面包与汽油的气息。它很少带有新橡木桶的风味。它的酸度能支撑各种甜度，从极干，到以贵腐葡萄或在树上结冻的葡萄酿成的浓郁甜酒。重点产区包括摩泽尔与莱茵高、阿尔萨斯、奥地利，以及澳大利亚的克莱尔谷与伊顿谷，后者的干型风格常带青柠气息。

白诗南（Chenin Blanc）

白诗南酸度高、香气中等，而且成熟不均，所以葡萄种植者常分好几批采收。这种弹性解释了卢瓦尔河惊人的风格范围：以刚成熟的葡萄酿造的起泡酒、Vouvray 与 Savennières 等干型与微甜酒款，以及以皱缩或贵腐葡萄酿成的甜酒，例如 Coteaux du Layon。在广泛种植它的南非，它既能酿出清新、果香丰富的酒，也能以老藤酿出更丰厚、有时经橡木桶的风格。

赛美蓉、琼瑶浆、灰皮诺与维欧尼

赛美蓉（Sémillon）果皮薄、容易感染贵腐菌，因此是 Sauternes 的主要品种；在澳大利亚的猎人谷，它会提早采收，酿成轻盈、低酒精度的干型酒，不经橡木桶，在瓶中陈年后发展出烤面包与蜂蜜的气息。琼瑶浆（Gewurztraminer）果皮呈桃红色，酸度低到中等、酒精度高，带浓郁的荔枝、玫瑰与甜香料香气，阿尔萨斯是它的经典产地。阿尔萨斯的灰皮诺（Pinot Gris）酿出丰厚、酒体饱满的酒，而同一个品种在意大利东北部以 Pinot Grigio 之名出现时，通常较早采收，酿出轻盈、中性、清新的酒。维欧尼（Viognier）是北罗讷河 Condrieu 的品种，酒体饱满，带杏子、桃子与花香，酸度低，所以在正确的时机采收至关重要。

主要黑葡萄品种详解

黑皮诺（Pinot Noir）

黑皮诺发芽与成熟都早，果皮薄，所以适合凉爽到温和的气候，也容易腐烂。它的酒颜色浅到中等，带草莓、覆盆子与红樱桃等红色水果，单宁低到中等、酸度中等到高，陈年后发展出森林地表与蘑菇的气息。它的经典产地是勃艮第，也是香槟不可或缺的品种。新世界的出色例子来自中奥塔哥、俄勒冈与加州较凉爽的地区，德国则以 Spätburgunder 之名种植它。

赤霞珠（Cabernet Sauvignon）

赤霞珠发芽与成熟都晚，所以需要温暖的地块才能完全成熟；未熟时会出现青椒般的草本气息。它果粒小、果皮厚，带来深色泽、高单宁与高酸度，以及黑醋栗、黑樱桃、薄荷与雪松的风味。它通常经橡木桶陈年，陈年潜力极佳。在波尔多左岸，它在温暖的砾石土壤上生长良好，并与梅洛和品丽珠混酿。其他重点产区包括纳帕谷、库纳瓦拉、玛格丽特河（Margaret River）与智利。

梅洛（Merlot）

梅洛比赤霞珠早熟，酿出的酒单宁较柔和、酸度中等，带李子、黑樱桃与巧克力风味。它适合波尔多右岸 Saint-Émilion 与 Pomerol 较凉的黏土，在那里主导混酿。它也广泛种植于智利、华盛顿州与意大利北部，常酿成柔和、果香丰富、适合早饮的风格。

西拉（Syrah 或 Shiraz）

西拉带来深色泽、中等到高的单宁与黑色水果。在北罗讷河温和气候下的 Hermitage 与 Côte-Rôtie，它呈现黑莓、黑胡椒、紫罗兰与咸香气息。在巴罗萨谷与麦克拉伦谷等澳大利亚温暖产区，它以 Shiraz 之名出现，更成熟、更饱满，带果酱般的黑色水果、巧克力，常有来自橡木桶的甜香料。澳大利亚、新西兰与南非较凉爽的地块，则酿出更接近罗讷河的风格。

歌海娜

歌海娜是晚熟品种，耐热耐旱，很适合在温暖干燥的气候中以杯型灌木种植。它很容易累积糖分，所以酒精度高，而相对较薄的果皮则带来较浅的颜色与较柔和的单宁。它呈现草莓、覆盆子等红色水果与辛香料，陈年后发展出皮革与果干气息。它是 Châteauneuf-du-Pape 等南罗讷河混酿酒的骨干，也是 Priorat 与 Navarra 的重要品种，并广泛用于桃红葡萄酒。

丹魄、桑娇维塞与内比奥罗

丹魄的名字源自它的早熟特性，果皮厚，带来中等的酸度与单宁与红色水果，非常适合长时间的橡木桶陈年。它是 Rioja 的主要品种，也以当地名称用于 Ribera del Duero 与 Toro，在葡萄牙则用于杜罗河谷。桑娇维塞是晚熟品种，酸度高、单宁中等到高，带红樱桃、李子与草本气息；它是 Chianti Classico 与 Brunello di Montalcino 的品种。内比奥罗发芽早、成熟晚，需要最好的地块；它的颜色浅且很快转为石榴红，酸度与单宁却很高，带红樱桃、玫瑰与焦油气息，在 Barolo 与 Barbaresco 拥有极佳的陈年潜力。

马尔贝克与仙粉黛

在门多萨的高海拔葡萄园，强烈的日照与凉爽的夜晚加深颜色并保留清新感，马尔贝克在那里酿出颜色深、带黑色水果与紫罗兰、单宁成熟柔和的酒；在 Cahors，它则更具单宁感、更粗犷。仙粉黛（Zinfandel）在意大利南部被称为 Primitivo，成熟不均，同一串中会同时有葡萄干般的果粒与未熟的果粒，而且容易累积高糖分，所以酒常常酒精度高、带果酱般的果味。

同一个品种，两种气候

在笔试答案中最可靠的得分方式之一，就是说明一个品种如何随气候改变。每个主要品种至少要学一个凉爽与一个温暖的例子。

经典混酿及其原理

混酿是结合不同品种长处的一种方式。学习每种经典混酿背后的逻辑，比背诵清单更有用，因为笔试题奖励的正是这种逻辑。

酒款主要品种各自的贡献
波尔多红葡萄酒赤霞珠、梅洛、品丽珠结构与黑醋栗；柔和与李子；芬芳与清新
波尔多白葡萄酒长相思、赛美蓉酸度与香气；酒体、质地与陈年潜力

香槟霞多丽、黑皮诺、莫尼耶皮诺细致与酸度；酒体与红色水果；果香与年轻时的易饮性

一个好习惯是：每当笔试题问到混酿酒，就为混酿中的每个品种各写一句话，说明它的贡献。这个简单的结构通常能拿到大部分的分数。

各产区的本地品种

除了国际品种之外，每个产区都有考官喜欢考的本地品种。依国家分组，并为每个品种配上一个重点风格。

  • 西班牙：Rías Baixas 的阿尔巴利诺，芳香、酸度高、带桃子气息；Rueda 的弗德乔，清新带草本；温暖东南部的莫纳斯特雷尔（Monastrell），强劲而成熟。
  • 葡萄牙：杜罗河谷的国产多瑞加，颜色深、带花香，用于波特酒与干型红葡萄酒；北部的 Alvarinho，酿造清新芳香的白葡萄酒；Bairrada 的 Baga，酸度与单宁都高。
  • 意大利：Soave 的卡尔卡耐卡；Prosecco 的格雷拉；巴贝拉，酸度高、单宁低；Valpolicella 与 Amarone 的科维纳；Taurasi 的艾格尼科，晚熟且单宁强；西西里的黑达沃拉；坎帕尼亚的菲亚诺与 Greco。
  • 奥地利与匈牙利：绿维特利纳，带白胡椒与绿色水果；蓝佛朗克（Blaufränkisch），带黑色水果与辛香料；福明，酸度高、容易感染贵腐菌，用于 Tokaji。
  • 希腊：Santorini 的 Assyrtiko，在炎热、多风的火山环境中仍保有高酸度；Naoussa 的 Xinomavro，酸度与单宁都高；Nemea 的 Agiorgitiko，柔和而果香丰富。
  • 南半球：南非的皮诺塔吉；智利的佳美娜；阿根廷萨尔塔的特浓情，花香浓郁。
  • 经典之外的法国：Muscadet 的勃艮第香瓜（Melon）；卢瓦尔河的品丽珠；博若莱的佳美。

容易混淆的品种

有些配对在选择题中一再造成错误。学会它们之间的关键差异，比把两者重新学一遍更快。

  • 长相思与赛美蓉：两者都用于波尔多白葡萄酒，但长相思带来酸度与香气，赛美蓉则带来酒体，并容易感染贵腐菌。
  • 赤霞珠与品丽珠：品丽珠更轻盈、更芬芳、更早熟，这就是它能在卢瓦尔河成功的原因。
  • Pinot Gris 与 Pinot Grigio：同一个品种，但名称通常代表不同的风格，阿尔萨斯丰厚，意大利东北部轻盈。
  • Grenache 与 Garnacha：同一个品种的法文与西班牙文名称，不是两个品种。
  • 内比奥罗与桑娇维塞：两者酸度与单宁都高，但内比奥罗颜色更浅，带玫瑰与焦油气息，属于皮埃蒙特；桑娇维塞则属于托斯卡纳，带红樱桃与草本气息。
  • 马尔贝克与佳美娜：两者在南美都很重要，马尔贝克在阿根廷，佳美娜在智利，而佳美娜在智利曾长期被误认为梅洛。

练习题与参考答案

我们自己出的题目：请解释为什么黑皮诺种植在勃艮第与中奥塔哥，而不是非常炎热的产区（4 分）。

一份有力的答案：黑皮诺发芽与成熟都早，所以能在生长季短或凉爽的产区达到成熟。在炎热气候中，它会成熟得太快，失去酸度与细致的红色水果香气，酿出果酱味重、松垮的酒。它的薄皮只能提供有限的颜色与单宁，因此需要缓慢成熟，在糖分过高之前发展出风味的复杂度。勃艮第（大陆型气候）与中奥塔哥（日照充足、夜晚凉爽）这类凉爽到温和的气候能保留酸度与清新的红色水果，带来这个品种为人熟知的优雅风格。

注意每一句都从品种的某个特性出发，并以它对酒的影响作结。这就是回答任何品种题目时应该使用的模式。

品种的学习例行练习

  • 为每个主要品种做一张卡片，一面写六问画像，另一面写两个形成对比的产区。
  • 每天复习几张卡片，并从三个方向测验自己：品种到产区、产区到品种、风格到品种。
  • 读一个产区时，把它的本地品种加入卡片组，并为每个品种联系一种风格。
  • 每周写一小段文字，解释某个品种在凉爽与温暖产区之间如何改变。

常见问题

WSET Level 3 有多少个葡萄品种？

没有一份固定要背的清单：课程深入涵盖主要的国际品种，并依产区介绍许多本地品种。关键是要知道它们的风格，以及产地与酿造如何改变它们。

背 WSET Level 3 品种的最佳方法是什么？

每天短时间练习混合题目（品种 ↔ 产区 ↔ 风格），再搭配闪卡，效果比读清单更好。The Wine Goat 会反复出你答错的品种，直到你记住为止。

品酒需要认识葡萄品种吗？

品酒考试不会要你说出品种，但认识品种画像能帮你描述结构，并得出正确的质量结论。

WSET Level 3 课程中提到的每个葡萄品种都要知道吗？

主要的国际品种需要深入了解，包括它们的画像、重点产区，以及气候与酿造如何改变它们。本地品种则依产区学习，通常是它们的主要风格与种植地点。先把主要品种学深，再随着读每个产区逐步累积本地品种，并用混合题目让它们全部保持活跃。

品种的特性如何帮助笔试答题？

大多数笔试题都在问一款酒为什么呈现某种风格。酸度、果皮厚度、成熟时间与香气强度等品种特性，常常是这个解释的第一环。以品种特性作为句子的开头、以它对酒的影响作结，是把知识转化为分数的简单可靠方法。

为什么有些品种有好几个名字？

品种在数百年间传播到各国，沿途取得了当地的名字。Grenache 在西班牙叫 Garnacha，在撒丁岛叫 Cannonau；丹魄在西班牙与葡萄牙有好几个地区名称；Zinfandel 与 Primitivo 是同一个品种。考题与酒标可能使用其中任何一个名称，所以值得双向学习同义名称。

Level 3 考生最常搞混哪些品种？

常见的混淆包括赤霞珠与品丽珠、波尔多白葡萄酒中的长相思与赛美蓉，以及内比奥罗与桑娇维塞，后两者同样酸度与单宁高，但颜色、香气与产区不同。Pinot Gris 与 Pinot Grigio 是同一个品种，名称通常暗示不同的风格。学会每组配对之间唯一的关键差异，是最快的解决方法。

认识品种对 Level 3 品酒单元有帮助吗？

有，但是间接的。你不会被要求说出品种，但认识典型画像能帮你有信心地判断结构，例如预期凉爽气候的雷司令酸度高，或年轻的赤霞珠单宁高，并得出合理的结论。品酒单元与理论分开评分，本身就需要至少 55%。
