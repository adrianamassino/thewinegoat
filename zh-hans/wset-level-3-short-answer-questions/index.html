WSET Level 3 简答题：示例与参考答案

4 题简答题是大多数 WSET Level 3 考生失分的地方。每题分成数个小题，得分靠的是解释因果关系——为什么某种气候造就某种风格、某项技术如何改变葡萄酒——而不是列出关键词。

以下是来自 The Wine Goat 题库的简答题，并附上能得分的要点。在 App 中，你可以写下自己的答案，并立即依这些重点评分：你答到了什么、遗漏了什么，以及你大概能拿几分。

样题与解答

阿尔萨斯（Alsace）。

阿尔萨斯位置如此偏北，为什么能酿出成熟的酒？四个贵族品种是哪些？各有什么风格？（5 分）

能得分的要点

凉爽至温和的大陆型气候；孚日山脉（Vosges）阻挡带雨的西风 → 云少、夏季晴朗、秋季干燥，糖分成熟度高（最干燥的年份会干旱）；最好的葡萄园位于最陡、面东／东南的斜坡，葡萄树低矮整枝以吸收辐射热；平原的葡萄树高架以防霜，用于 Crémant；北部最凉爽；多样的地质影响风格；病害少 → 有机／自然动力法；Riesling 是种植最多的贵族品种：不甜、中等至饱满酒体、中等酒精、高酸度、柑橘、核果、钢铁般的矿物感（花香比德国少；现在较多带糖分）；Gewurztraminer：浓郁的荔枝、玫瑰、甜香料，粉红色果皮 → 金黄色、饱满、油润、中低酸度、高酒精（14%）；Pinot Gris：浓郁、饱满、高酒精，酸度比 Gewurz 高、香气较少，新鲜水果与果干、蜂蜜；Muscat（最好的是 Muscat Blanc à Petits Grains，橙花、玫瑰、葡萄味，轻盈至中等酒体，中低酸度；Ottonel 种植较多，因为 Petits Grains 容易落果与腐烂）

卢瓦尔河谷（Loire Valley）。

解释为什么 Chenin Blanc 在 Vouvray、Savennières 与 Coteaux du Layon 呈现如此不同的风格。（6 分）

能得分的要点

高酸、非芳香型；成熟不均，即使同一串也不均 → 需分多次采收，未成熟时带青绿草本味；风格取决于成熟度：刚成熟（10–11%）用于起泡酒，越成熟则依序酿成不甜、半甜、甜酒（萎缩或贵腐）；趋势是更成熟、带几克残糖的不甜酒；从苹果到热带水果，不甜酒带钢铁与烟熏感，贵腐酒带杏／柑橘皮；可陈年数十年，发展出蜂蜜、烤面包、干草；Vouvray（图尔以东，Touraine）：凉爽、黏土，依年份从不甜到极甜的静止葡萄酒，另有起泡酒，轻盈至中等酒体，清新果香花香，很少用新橡木桶；Anjou／Saumur：Saumur 产传统法起泡酒，Anjou 不甜酒常用新橡木桶；Savennières 与 Coteaux du Layon 位于更温暖干燥的 Anjou 西部（Mauges 丘陵、多石土壤）→ 中等至饱满酒体、花香较少；Savennières：日照充足，空气流通抑制贵腐，晚摘、饱满的不甜酒可陈年数十年；Coteaux du Layon：受屏障的 Layon 河谷，有贵腐，Quarts de Chaume 与 Bonnezeaux 名列世界最伟大的甜酒

卢瓦尔河：红葡萄酒与桃红葡萄酒。

描述 Touraine（Chinon、Bourgueil、Saumur-Champigny）的 Cabernet Franc 红葡萄酒，以及 Anjou 的桃红葡萄酒。（6 分）

能得分的要点

Cabernet Franc 适合卢瓦尔河，因为它开花与成熟都早；Chinon（卢瓦尔河南岸）、Bourgueil 与 Saint-Nicolas-de-Bourgueil（北岸）：沙质土壤 → 轻盈果香、适合早饮；面南的石灰岩与黏土斜坡 → 更饱满、单宁更高；部分使用橡木桶，最好的酒可演化多年；Saumur 与 Saumur-Champigny 酒体与单宁较轻，多汁莓果、花香，最适合年轻时饮用，可冰镇（部分酒庄较饱满）；Gamay 是第二重要的黑葡萄（Touraine、Anjou），果香、适合早饮；Pinot Noir 在中央产区（Central Vineyards）少量种植，轻盈；桃红葡萄酒：Rosé de Loire 一定是不甜，至少 30% Cabernet Franc／Sauvignon，主要产于 Anjou-Saumur；Cabernet d'Anjou 质量最高，一定是半甜，Cabernet Franc + Sauvignon；Rosé d'Anjou 较不甜，主要是 Grolleau（高产量的当地品种）加 Cabernet Franc；Touraine 桃红葡萄酒不甜清新，使用多种品种；Sancerre 桃红葡萄酒以 Pinot Noir 酿成，浅色、不甜、细致；直接压榨或短时间浸皮，在惰性容器中控温发酵

简答题在考试中的定位

WSET Level 3 证书包含两个独立单元。理论单元是一份结合 50 题选择题与 4 题简答题的考卷；品酒单元则是两款酒的盲品。每个单元分开评分，都至少需要 55% 才能通过；如果某个单元没过，只需重考该单元。因此简答题属于理论单元，与选择题并列，两者共同决定你能否通过理论。

这就是为什么简答题值得专门准备。一位选择题很强、却在空白页面前脑袋一片空白的考生，即使知识充足，也可能在理论单元失利。好消息是，写出能拿分的答案是一种可以学会的技巧。一旦了解分数如何给予，你就能把同样的知识转换成更多分数。

简答题如何评分

每题围绕一个主题，例如某个产区、某种风格或某个酿造选择，并分成数个小题，各自标示配分。阅卷者依据一份可接受要点的清单评分。每个正确、切题且足够精确的要点都能得一分，直到该小题的总分为止。用不同的说法重复同一个要点、写题目没问的内容，或加上对任何葡萄酒都成立的笼统叙述，都不会得分。

这带来三个实际的结果。第一，配分告诉你至少需要几个独立的概念：一个 4 分的小题至少需要四个不同且正确的要点，多写一两个是合理的安全余裕。第二，精确会得到奖励：写“冬季寒冷、夏季短而温暖的凉爽大陆型气候”，会比只写“凉爽气候”得到更多分。第三，解释往往本身就是要点的一部分：如果题目问“为什么”，一个没有联系到其影响的事实可能一分都拿不到。

典型题目的结构剖析

大多数题目都遵循一个可辨认的模式。一段简短的引言点出主题，例如某个产区或某种风格。接着是各个小题，常常从描述进展到解释。一组典型的小题可能要求你描述某个产区的气候、解释它如何影响葡萄、描述一款酒如何酿造，最后解释为什么这款酒具有特定的风格或价格。每个小题聚焦在从葡萄园到酒杯这条链上的不同环节。

动笔前先把所有小题一起读过是很有价值的。这能让你看出阅卷者希望每项信息出现在哪里，避免把最好的要点用在 a 小题，而它们其实属于 c 小题。这也能避免重复，因为写在错误小题中的要点，可能不会在真正需要的地方获得分数。

每道题都适用的五步骤方法

  1. 读完整道题目，包括所有小题，并把每个小题的指令词与配分画线标出。
  2. 花大约一分钟在页边用关键词写下规划：每个预期的分数写一个关键词，再多加一两个。
  3. 把每个关键词分配到正确的小题，确保没有重复、也没有遗漏。
  4. 把每个要点写成简短、完整的句子，联系原因与结果，并使用精确的考试词汇。
  5. 快速重读：每个小题都回答了吗？有写出品种、地点与技术吗？每个“为什么”都有对应的“因为”吗？

规划是考生在压力下最常跳过的步骤，却也是最能保住分数的步骤。三十秒写下关键词，就能避免你忘记某个小题、把同一个要点写两次，或写到一半就没有想法。

把事实转换成分数的因果链

几乎每一道 Level 3 简答题，都能用同一条逻辑链来回答。从自然因素出发，接着写人为的决策，最后落在酒上。学会用这条链思考，你就很少会缺要点。

链中的环节要提到什么因果连接句示例
气候与天气温度、日照、降雨、日夜温差、霜害等风险凉爽的夜晚保留酸度，所以酒喝起来清新
地块与土壤坡度、坡向、海拔、水域、排水、保热能力面南的斜坡接收更多日照，有助于葡萄成熟
葡萄品种天然酸度、果皮厚度、成熟时间、芳香特质早熟品种适合短暂的生长季
葡萄园管理产量、树冠、采收时机、手工或机械采收低产量让风味浓缩，有助于提升质量
酿造发酵温度与容器、乳酸转化、酒泥、橡木桶、混调在不锈钢槽中低温发酵，保留初级果香
陈年容器、时间、接触氧气的程度、瓶中陈年在旧木桶中长时间陈年，增添三级香气，又不会带来强烈的橡木风味
最终的风格与质量结构、香气、陈年潜力、影响价格的因素高酸度与浓缩度让这款酒具有陈年潜力

并不是每一题都需要用到每个环节。指令词与小题会告诉你阅卷者要的是链上的哪一段。但熟悉这条链，代表你写到气候时，会自动想到它对葡萄、再对酒的影响，而这正是 explain（解释）题所奖励的。

弱答案与强答案

来看一道我们自己编写的练习题：解释为什么 Mosel 能酿出轻盈、高酸度的高质量 Riesling（6 分）。弱答案读起来像这样：Mosel 很冷，有板岩土壤和陡坡，Riesling 酸度高，酒很轻盈。每个叙述都正确，但大部分只是清单。它或许能拿到两三分，因为好几个叙述缺少让它们切题的联系。

强答案涵盖类似的事实，但会加以解释。Mosel 是最北的优质葡萄酒产区之一，属于凉爽大陆型气候，所以葡萄成熟缓慢并保有非常高的酸度。最好的葡萄园位于河岸上方陡峭、面南的斜坡，能最大化日照，让葡萄在边际气候中也能成熟。河流反射阳光并调节气温，降低霜害风险。板岩土壤白天吸收热量、夜间释放，有助于成熟，在陡坡上排水也很好。Riesling 晚熟、耐霜，又能保持酸度，因此漫长而凉爽的生长季能发展出强烈的香气却不会累积太多糖分，带来中低酒精与轻盈酒体。这些酒通常不使用新橡木桶，保留了明显的果香与花香特质，最好的酒款能陈年多年，发展出蜂蜜与汽油调性。

数一数概念：每个句子至少带一个可得分的要点，而每个要点都回答了“为什么”。这就是“知道事实”与“把事实转换成分数”的差别。

更多练习题的参考答案

以下是我们依照考试形式自行编写的练习题。答案展示了能得分的要点类型；它们是良好答题技巧的示例，并非官方评分标准。

传统法起泡酒

题目：描述香槟这类传统法起泡酒如何酿造，并解释这个流程如何赋予酒款独特的风味（8 分）。

文字版参考答案：葡萄在酸度高、糖分相对低时提早采收，并轻柔压榨，常以整串压榨，以避免从黑葡萄中萃取出颜色与苦味。基酒发酵至不甜，再把许多酒批混调，打造一致的酒庄风格，常会加入过去年份的储备酒。混调后的酒与葡萄酒、糖和酵母的混合液一起装瓶，在封闭的瓶中启动二次发酵；二氧化碳无法逸出而溶入酒中，形成气泡。发酵后，酒与死去的酵母细胞（酒泥）一起长时间静置，酵母自溶释放出的物质带来面包、饼干与烤面包香气，以及更绵密的质地。接着通过转瓶把酒泥移到瓶颈，冷冻后在除渣时去除。最后添加少量葡萄酒与糖（补液，dosage），决定最终甜度并平衡高酸度。与酒泥接触的时间越长，自溶风味越明显，这也是年份酒与顶级酒款比年轻混调更复杂的原因之一。

博若莱的二氧化碳浸泡法

题目：解释二氧化碳浸泡法如何影响博若莱（Beaujolais）的风格（4 分）。

文字版参考答案：完整未破碎的 Gamay 葡萄串被放入充满二氧化碳的容器中。在无氧的情况下，发酵在每颗完整的果粒内部开始，产生少量酒精以及樱桃酒（kirsch）、香蕉与泡泡糖等独特香气。颜色从果皮中萃取出来，而萃取出的单宁相对较少，所以酒的颜色深，但口感柔和、单宁低。果粒最终破裂，果汁再以一般方式完成发酵。成品是果香丰富、轻盈至中等酒体、适合年轻时饮用的红葡萄酒；不过许多酒庄只采用部分二氧化碳浸泡技术，为特级村（cru）酒款保留更多结构。

Rioja 的陈年等级

题目：描述标示 Crianza、Reserva 与 Gran Reserva 的 Rioja 红葡萄酒的陈年规定，并解释陈年如何影响风格（6 分）。

文字版参考答案：Crianza 红葡萄酒必须陈年至少两年，其中至少一年在橡木桶中。Reserva 必须陈年至少三年，其中至少一年在橡木桶中。Gran Reserva 必须陈年至少五年，其中至少两年在橡木桶中。传统上使用美国橡木，带来香草与椰子调性；如今许多酒庄也使用法国橡木，带来更细腻的烘烤与香料调性。长时间陈年柔化了 Tempranillo 的单宁，而在橡木桶中缓慢接触氧气，则发展出皮革、果干与土壤等三级香气，年轻酒款鲜明的红色水果则逐渐消退。因此，陈年时间较长的等级往往更复杂、更具咸香风味、颜色更浅，常呈石榴红并带黄褐色边缘。

Fino 与 Oloroso 雪莉酒

题目：比较 Fino 与 Oloroso 雪莉酒的酿造方式，以及这如何影响它们的风格（6 分）。

文字版参考答案：两者都以 Palomino 葡萄发酵成不甜的基酒，并在索莱拉系统（solera）中陈年，混调不同年龄的酒以维持风格一致。酿造 Fino 时，最细致的基酒会加烈到约 15 至 15.5% 酒精，在这个浓度下，一层称为酒花（flor）的酵母能在酒的表面生长。酒花保护酒不接触氧气，并增添面包、酵母与杏仁调性，所以 Fino 颜色浅、酒体轻盈、极不甜。酿造 Oloroso 时，较饱满的基酒会加烈到约 17%，使酒花无法生长，因此酒会进行氧化陈年。氧气逐渐把酒色加深成褐色，并发展出核桃、太妃糖与皮革调性，而蒸发则使酒浓缩，带来更饱满的酒体与更高的酒精浓度。两者天生都是不甜的，不过也有加甜的风格。

建立一套可重复使用的解释库

许多因果联系会一再出现在不同题目中，无论是哪个产区。把它们学成可重复使用的句子，你就能套用到课程大纲的任何地方。以下是几个例子。

  • 日夜温差大能保留酸度与芳香物质，因为葡萄在夜间会降温。
  • 海洋影响调节气温，延长生长季并减少极端天气。
  • 高海拔降低平均气温并增加日照强度，酿出更清新、颜色更深的酒。
  • 贫瘠且排水良好的土壤限制生长势，所以葡萄树把能量集中在数量较少、更浓缩的葡萄上。
  • 低产量让风味浓缩，有助于提升质量与价格。
  • 手工采收能挑选健康的葡萄串，而整串压榨或在陡坡上采收时必须手工进行。
  • 在不锈钢槽中低温发酵，保留初级果香与花香。
  • 乳酸转化柔化酸度，并可能增添黄油调性。
  • 酒泥接触增添质地以及咸香、面包般的调性。
  • 新橡木桶增添香草、烘烤与香料风味，以及一些单宁；旧橡木桶则让酒温和地接触氧气，而不会增添太多风味。

把每个可重复使用的联系写在闪卡上，背面写一个适用的产区。复习新产区时，问问自己哪几张卡片能解释它的风格。这能把零散的事实变成一套你能带进任何题目的工具。

笔试部分的时间分配

要回答四道题目，时间分配和知识一样重要。许多考生第一题写得很长，最后一题却匆匆带过，失去的分数远比多拿的多。根据学校确认的考卷总时长，以及你为选择题规划的时间，为每题设置固定的时间，并反复练习直到成为反射动作。

一个实用的原则是依配分比例分配时间：配分加倍的小题，大约值得两倍的时间。如果卡住了，先写下你有把握的要点，留下空白，继续往下写；最后如果还有时间，可以再回来。部分作答的题目仍能拿到分数，没作答的题目则一分都没有。

如何练习与自我评分

最有效的练习是规律且简短的。每天限时写一篇答案，远比在一个周末写十篇有用。写完后，把答案与重点清单比对，数一数你实际答到的要点，而不是你本来想写的。要严格：如果某个要点含糊或没有解释，就不要给自己那一分。

随着时间累积，找出你遗漏要点的模式。也许你总是忘记写酿造的影响，或描述了气候却没写出其结果。这些模式会告诉你该复习什么。在纸上练习也很重要，因为手写比打字慢，而考试是手写作答的。

有效的每周例行练习

  • 周一到周四：每天针对正在读的产区限时写一篇简答，并依重点评分。
  • 周五：重写本周最弱的一篇答案，目标是多加两个可得分的要点。
  • 周末：做一组两题、取自前面章节的综合题，让旧主题保持熟练。
  • 每两周一次：在考试条件下做一份完整的理论模拟考，包括选择题与四题简答题。

简答题最后检查清单

  • 我在动笔前读完所有小题，并把每个指令词与配分画线标出。
  • 我为每一分规划了一个关键词，再加上少许余裕，并把每个关键词分配到对应的小题。
  • 题目中的每个“为什么”，在我的答案中都有一个“因为”。
  • 我写出了具体的品种、地点、技术及其影响。
  • 我避免了重复与不相关的内容。
  • 我遵守了每题的时间，并尝试回答了每个小题。

常见问题

WSET Level 3 考试有几道简答题？

理论考试中有 4 道简答题，每题分成数个小题。

WSET Level 3 的简答题如何评分？

分数给予准确、切题且能解释因果关系的要点，所以有结构、具体的答案比一串关键词得分更高。

哪里可以练习有评分的 WSET Level 3 简答题？

The Wine Goat 有 101 道简答题，可依重点实时评分，每题都附有参考答案。

WSET Level 3 每道简答题各占几分？

每道简答题分成数个小题，每个小题的配分都标示在考卷上。把这些数字当作你的指引：配分告诉你阅卷者预期有几个不同且正确的要点。多写一两个切题的要点能提供安全余裕，但用不同的说法重复同一个概念，永远不会多得一分。

如果简答题写得不好，还能通过理论单元吗？

理论单元结合了选择题与简答题，要通过就必须在两个部分各自达到至少 55%：选择题再强也无法弥补薄弱的简答题。由于简答题既看知识也看答题技巧，几周的规律练习通常就能带来明显的进步。

应该写完整的句子还是条列重点？

简短完整的句子是最安全的选择，因为它让你能把原因联系到结果，而这正是解释题所奖励的。条列重点可以用在只要求你说出或列出的题目，但即使如此，每个要点都应该精确。避免没有上下文的单一关键词：它们常常无法向阅卷者证明你理解事情发生的原因。

如果某个小题不会，该怎么办？

不要留白。用气候、地块、品种、葡萄园、酿造与风格这条链，找出你有把握的相关要点，清楚写下来。部分作答常常能拿到一些分数。接着继续往下写，保住其他题目的时间，最后如果还有时间，再回来补充细节。

考前多久应该开始练习简答题？

从上课的头几周就开始，而不是等到考前。及早写答案，能帮助你以考试所奖励的因果形式学习内容，也能培养在时间压力下书写所需的速度。从一开始就每天简短练习，远比在最后几天密集书写有效得多。
