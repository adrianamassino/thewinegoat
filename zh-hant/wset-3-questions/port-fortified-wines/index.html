1 Douro 的三個 Port 子產區是哪三個？

顯示答案

答案： Baixo Corgo、Cima Corgo、Douro Superior

原因： Baixo Corgo 最涼爽、最多雨，酒款最輕盈；Cima Corgo 擁有最多頂級葡萄園；Douro Superior 也享有盛名。越往東越炎熱乾燥。

2 是什麼為 Douro 擋住了帶來雨水的大西洋風？

顯示答案

答案： Serra do Marão 山脈

原因： 這裡是溫暖的大陸性氣候；葡萄園從 Porto 與 Gaia 上游 70 公里處開始。

3 Port 的發酵在酒精濃度達到多少時被中止？

顯示答案

答案： 5–9% abv，大約 24–36 小時後

原因： 時間太短，一般的萃取方式強度不夠：因此會使用腳踩、自動釀酒槽（autovinifier）、活塞系統與機械 lagar。

4 什麼是 lagar？

顯示答案

答案： 用來以腳踩踏葡萄的淺型花崗岩槽

原因： 它是其他方法的比較基準；非常耗費人力，但部分高級酒款至今仍在使用。

5 Douro 種植最廣的葡萄品種是哪一個？

顯示答案

答案： Touriga Franca

原因： 種植最多的是 Touriga Franca；最受推崇的是 Touriga Nacional（產量低）。

6 加烈後的 Port 酒精濃度是多少？

顯示答案

答案： 19-22% abv

原因： 加烈會殺死酵母；加烈的時機取決於葡萄汁的糖度與想要的甜度。

讀書筆記：WSET Level 3 波特酒與加烈酒

WSET Level 3 的 Port 題目有清楚的模式：Douro 的氣候與葡萄園、加烈如何運作，以及最重要的，各種 Port 風格之間的差異。其他加烈酒的題目，例如天然甜葡萄酒（Vins Doux Naturels）、Madeira 與 Rutherglen Muscat，考的是加烈的時機與陳年方式如何塑造風格。Sherry 有自己的專頁；這份筆記涵蓋 Port 以及上面練習題背後的其他加烈酒。

什麼是加烈酒

加烈酒是加入了葡萄烈酒的葡萄酒。如果在發酵過程中加入烈酒，它會殺死酵母並留下天然的葡萄糖分，所以酒是甜的：Port、天然甜葡萄酒與 Rutherglen Muscat 就是這樣釀成的。如果在發酵結束後才加入烈酒，酒就是不甜的，除非之後再加甜，大多數 Sherry 就屬於這種情況。光是這一個概念，就能解釋加烈酒考題中很大一部分的答案。

Douro：Port 的氣候、土壤與葡萄園

Port 來自葡萄牙北部的 Douro 河谷。Serra do Marão 山脈為河谷擋住大西洋的雨水，所以氣候是溫暖的大陸性氣候，越往東越炎熱乾燥。夏季非常炎熱、雨量少，葡萄樹可能遭受水分逆境。

  • 片岩土壤占主導：這種岩石呈垂直方向裂開，所以葡萄樹的根能在乾燥的夏季深入地下尋找水分。
  • 河谷兩側非常陡峭，因此葡萄園都種在梯田上。
  • Socalcos 是以乾砌石牆支撐的傳統狹窄梯田，非常耗費人力。
  • Patamares 是用推土機開出的較寬梯田，沒有石牆，可以進行部分機械化作業。
  • Vinha ao alto 是沿著坡面垂直種植，在坡度允許的地方使用。

Douro 分為三個子產區。Baixo Corgo 位於最西邊，最涼爽也最多雨，出產較輕盈的酒，用於基本款的 Ruby 與 Tawny。以 Pinhão 為中心的 Cima Corgo 擁有大部分頂級葡萄園（quinta）。位於東邊的 Douro Superior 最炎熱乾燥，對優質葡萄酒的重要性日益提升。

Port 的葡萄品種

Port 通常是混調酒。Touriga Nacional 是最受推崇的品種，顏色深、單寧高、酒體飽滿，帶濃郁的黑色水果與花香，但產量低。Touriga Franca 是種植最廣的品種，帶來香氣與細緻度。Tinta Roriz（Tempranillo）、Tinta Barroca 與 Tinto Cão 則構成主要品種名單的其餘部分。在老葡萄園中，多品種混植的田間混釀（field blend）仍很常見。

Port 如何釀造：萃取與加烈

  1. 葡萄經破碎後開始發酵，但發酵只會持續約 24 到 36 小時。
  2. 因為發酵時間很短，萃取必須快速而強烈：會使用在 lagar 中腳踩、機械 lagar、自動釀酒槽，以及淋汁或活塞系統。
  3. 當葡萄汁達到約 5 到 9% abv 時，把酒液排出，並與約 77% abv 的葡萄烈酒（aguardente）混合。
  4. 烈酒殺死酵母，留下殘糖；最終的 Port 約為 19 到 22% abv。
  5. 接著進行陳年，可以在限制氧氣接觸的大型容器中（ruby 風格），或在允許氧化的較小木桶中（tawny 風格）。

陳年的地點很重要。傳統上，Port 在靠近海岸的 Vila Nova de Gaia 酒窖中陳年，那裡較涼爽潮濕。在較炎熱的 Douro 陳年的酒，可能會發展出一種常被稱為「Douro bake」的煮熟、烘烤風味。

WSET Level 3 的 Port 風格：ruby 與 tawny 兩大家族

每一種 Port 風格都屬於兩大家族之一。Ruby 風格在大型容器中陳年、接觸的氧氣很少，以保留深沉的顏色與新鮮的紅色與黑色水果；最好的酒款會在瓶中繼續熟成。Tawny 風格則在小型木桶（約 550 公升的 pipe）中陳年多年，氧化讓顏色轉為黃褐色，風味轉向堅果、焦糖、咖啡與果乾。

其他加烈酒：VDN、Madeira 與 Rutherglen Muscat

天然甜葡萄酒 Vins Doux Naturels（法國）

天然甜葡萄酒是在發酵過程中加烈（mutage）的甜酒。Muscat VDN，例如南隆河的 Muscat de Beaumes-de-Venise 與 Roussillon 的 Muscat de Rivesaltes，通常以 Muscat Blanc à Petits Grains 釀造，並在年輕時隔絕氧氣裝瓶，以保留明顯的葡萄、花香與橙花香氣。Roussillon 的 Grenache VDN，例如 Banyuls 與 Maury，可以釀成還原風格，果味豐富、顏色深沉；也可以釀成氧化風格，在接觸氧氣的情況下陳年，帶堅果與 rancio 風味。

Madeira（葡萄牙）

Madeira 的獨特之處在於它會被刻意加熱。在 estufagem 法中，酒在槽中加熱至少三個月，速度較快，用於平價酒款。在 canteiro 法中，酒在溫暖閣樓的木桶中緩慢陳年多年，用於最好的酒款。熱與氧化帶來焦糖、太妃糖、堅果與果乾風味，以及非常高的酸度，並讓 Madeira 極為長壽，開瓶後也很穩定。甜度取決於加烈的時機：甜型較早加烈，不甜型則較晚。高貴品種由最不甜到最甜依序為：Sercial、Verdelho、Boal（Bual）與 Malmsey（Malvasia）。Tinta Negra 是種植最多的品種，大多數 Madeira 都用它釀造。

Rutherglen Muscat（澳洲）

Victoria 的 Rutherglen 屬於炎熱的大陸性氣候。一種深色果皮的 Muscat Blanc à Petits Grains 被留在樹上晚收、部分乾縮，使糖分濃縮。發酵很早就以烈酒中止，保留非常高的糖分。酒在老木桶中陳年，常放在炎熱的棚屋裡，並以分層系統跨年份混調。結果是非常甜、非常濃縮的酒，帶果乾、太妃糖、咖啡與香料風味。四個品質等級代表酒齡與豐厚度逐級提升：Rutherglen、Classic、Grand 與 Rare。

簡答題範例：Tawny 與 Vintage Port 的比較

考試風格的題目：解釋為什麼 20 Year Old Tawny 與年輕的 Vintage Port 喝起來如此不同。好的答案：兩者在加烈之前的釀造方式相同，都是短時間發酵、強烈萃取，再以 aguardente 加烈並留下殘糖。Tawny 在小型 pipe 中陳年多年，氧氣緩慢進入，顏色褪成黃褐色，一級果香轉為果乾，並發展出堅果、焦糖與咖啡的風味；它經過過濾，可以直接飲用。Vintage Port 來自單一宣告年份，只在大型容器中陳年 2 到 3 年就不過濾裝瓶，所以保有深沉的顏色、濃郁的黑色水果與紮實的單寧，需要數十年的瓶中陳年才會變得柔順，並會產生需要醒酒換瓶的沉澱。

簡答題範例：ruby Port 如何保留果味

題目：解釋 Reserve ruby Port 的釀造方式，如何讓酒擁有濃郁的果味、深沉的顏色與甜度。（參考答案）

Port 的發酵時間很短，因為只進行 24 到 36 小時就被中止，所以顏色與單寧必須非常快速地萃取出來。生產者使用強力的方法，例如在 lagar 中腳踩、帶活塞的機械 lagar，或自動釀酒槽與淋汁。這種快速而強烈的萃取，帶來深沉的顏色，以及平衡甜度與酒精所需的單寧。

當發酵中的葡萄汁達到約 5 到 9% 酒精時，就以約 77% abv 的葡萄烈酒加烈。酵母被殺死，因此保留了大量天然葡萄糖分，最終的酒約有 19 到 22% 酒精。接著，ruby Port 在大型老容器中短暫陳年，例如大型橡木槽或不鏽鋼槽，這些容器限制了與氧氣的接觸，保留新鮮的黑色水果。裝瓶前會進行澄清與過濾，讓它可以直接飲用且不會產生沉澱。Reserve ruby 以品質較高的酒釀造，比基本款 ruby 更濃郁、更複雜。

這裡大部分的分數來自兩個連結：短時間發酵導致強力萃取，以及氧氣接觸少的大型老容器保留果味。把這兩點都寫成因果關係。

波特酒與加烈酒的常見錯誤

  • 說 Port 是在發酵結束後才加烈：加烈會中斷發酵，這就是酒之所以甜的原因。
  • 把 tawny Port 描述成以白葡萄釀造：tawny 來自黑葡萄，它的顏色來自在小型木桶中長時間的氧化陳年。
  • 把 LBV 和 Vintage Port 搞混：LBV 來自單一年份，但在木桶中陳年四到六年；Vintage 只在木桶中待約兩年，主要在瓶中陳年。
  • 忘了天然甜葡萄酒和 Port 一樣，是在發酵過程中加入中性葡萄烈酒，但烈酒濃度更高、用量更少。
  • 忽略 Madeira 的加熱過程（estufagem 或 canteiro），而這正是它開瓶後依然穩定的原因。

品飲單元中的加烈酒

在 Level 3，理論與品飲是兩個獨立的單元，各自最低需要 55%，沒過的單元單獨重考。加烈酒可能出現在品飲考試中，所以要練習完整描述一款加烈酒。注意高酒精，你會感覺到溫熱感；並仔細判斷甜度，因為高酸度或高單寧可能讓甜酒顯得沒那麼甜。Ruby Port 是深寶石紅或紫色，帶黑色水果與紮實的單寧；tawny 則是黃褐色或石榴紅色，帶果乾、堅果、焦糖，單寧較柔和。在結論中，判斷這款酒是現在就適飲，還是具備繼續發展的結構。

在 WSET Level 3 中，ruby Port 與 tawny Port 有什麼不同？

Ruby Port 在大型容器中陳年、接觸的氧氣很少，所以保有深沉的顏色與新鮮的紅色與黑色水果。Tawny Port 則在小型木桶中陳年多年，緩慢的氧化讓顏色轉為黃褐色，並發展出堅果、焦糖與果乾風味。Vintage、LBV 與 Reserve 屬於 ruby 家族；標示酒齡的 Tawny 與 Colheita 屬於 tawny 家族。

LBV 和 Vintage Port 有什麼不同？

兩者都來自單一年份。Vintage Port 只在宣告年份釀造，2 到 3 年後不經過濾裝瓶，需要長時間瓶中陳年與醒酒換瓶。LBV 在採收後 4 到 6 年裝瓶，通常經過過濾，所以更柔順，上市即可飲用，不過未過濾的 LBV 可能會產生沉澱。

為什麼 Madeira 要加熱？

加熱重現了在熱帶高溫中長途航海的效果，歷史上這種航程讓酒變得更好。在 estufagem 中，酒在槽中加熱至少三個月；在 canteiro 中，酒在溫暖的閣樓裡緩慢陳年。熱與氧化創造出焦糖、堅果與果乾風味，並讓 Madeira 極為穩定且長壽。

天然甜葡萄酒中的 mutage 是什麼？

Mutage 是在發酵中的葡萄汁裡加入葡萄烈酒以中止發酵，保留天然葡萄糖分。它用於法國的天然甜葡萄酒，例如 Muscat de Beaumes-de-Venise、Banyuls 與 Maury。Muscat VDN 通常在年輕時裝瓶，以保留葡萄與花香；而部分 Grenache VDN 則經氧化陳年，帶出堅果風味。

Port 使用哪些葡萄品種？

主要的 Port 葡萄品種是 Touriga Nacional，最受推崇，顏色深、果味濃郁，但產量低；Touriga Franca，種植最廣；以及 Tinta Roriz（Tempranillo）、Tinta Barroca 與 Tinto Cão。大多數 Port 都是混調酒，老葡萄園中常有多品種的田間混釀。

為什麼 Port 的發酵時間這麼短？

當葡萄汁達到約 5 到 9% 酒精時就會加烈，通常只經過 24 到 36 小時，以保留天然葡萄糖分。在這麼短的時間內，釀酒師必須萃取出足夠的顏色與單寧來平衡甜度與高酒精，這就是為什麼要使用腳踩、機械 lagar 與自動釀酒槽等強力方法。

開瓶後的 Port 可以保存多久？

取決於風格。Ruby 與 tawny Port 經過過濾，相當穩定，開瓶後可保存數週；而 tawny 在木桶中已經接觸過氧氣，通常保存得最久。Vintage Port 與未過濾的 LBV 最好在一兩天內喝完。Madeira 是最耐放的，因為它在釀造過程中已經氧化並加熱過。

Port 會出現在 WSET Level 3 的品飲單元嗎？

有可能。理論與品飲是兩個獨立的單元，各自需要至少 55%。如果你品飲到一款加烈酒，要描述高酒精、甜度等級、單寧，以及果味或三級風味特徵，然後判斷品質與適飲程度。你不需要說出它的風格，但你的描述應該精確到足以支持合乎邏輯的結論。

Single Quinta Vintage Port 和經典的 Vintage Port 有什麼不同？

經典的 Vintage Port 通常混調了生產者多座葡萄園中最好的酒，只在最好的年份宣告。Single Quinta Vintage Port 來自單一酒莊，常在品質好但未宣告為經典年份的年份釀造。兩者都在年輕時不經過濾裝瓶，都需要長時間瓶中陳年。

tawny Port 適合搭配什麼食物？

Tawny Port 帶果乾、堅果與焦糖風味，很適合搭配以堅果、焦糖或果乾為主的甜點，例如杏仁塔或焦糖布丁，也適合搭配熟成的硬質乳酪。它通常略微冰涼後侍酒。酒的甜度至少要和甜點一樣高，否則酒會嚐起來單薄而尖銳。
